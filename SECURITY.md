# Security Policy

## Scope

Security reports should concern the source code or packaged application of Tarkov Gamma Manager.

## Reporting

Please use a private GitHub security advisory when the repository is configured to accept security advisories. If that feature is not available, open a regular issue without publishing sensitive exploit details until a maintainer can review the report.

Do not include passwords, personal data, private keys, or other secrets in public issues.

## Anti-cheat note

The project is intended as a monitor/display utility. It does not intentionally read or write Tarkov process memory, inject DLLs into the game, install kernel drivers, or modify Tarkov files.

No anti-cheat compatibility guarantee is provided. Anti-cheat behavior can change independently of this project.
