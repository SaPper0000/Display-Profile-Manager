# Visual Studio 빌드 안내

1. 이 폴더 안의 `Tarkov-Gamma-Manager-v1.4.sln`을 Visual Studio 2022에서 엽니다.
2. .NET Framework 4.7.2 Developer/Targeting Pack이 설치되어 있어야 합니다.
3. 솔루션 탐색기에서 `Gamma Manager` 프로젝트가 정상적으로 로드되는지 확인합니다.
4. 구성: `Release`, 플랫폼: `Any CPU`를 선택하고 솔루션 다시 빌드를 실행합니다.

주의: ZIP 바깥의 다른 위치로 .sln만 옮기지 말고 프로젝트 폴더 구조를 그대로 유지하세요.
