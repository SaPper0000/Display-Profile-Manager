# Tarkov Gamma Manager v1.4.3

Escape from Tarkov용 휴대형 Windows 디스플레이 감마/프로필 관리자입니다.

## v1.4.3 변경 사항

- 지원되는 AMD 디스플레이에 **채도(Saturation)** 조절 기능을 추가했습니다.
- NVIDIA 디스플레이에 **디지털 바이브런스(Digital Vibrance)** 조절 기능을 추가했습니다.
- 채도 / 디지털 바이브런스 오른쪽의 **수치 입력칸에 키보드로 직접 값 입력**이 가능합니다.
- 값을 입력한 뒤 **Enter**를 누르거나 입력칸에서 포커스를 벗어나면 값이 적용됩니다.
- 기존 모니터별 프로필, 게임 자동 적용, 핫키, 백업/복원 기능은 그대로 유지됩니다.
- 한글 버전과 영어 버전을 별도로 제공합니다.
- 버전을 **1.4.3**으로 업데이트했습니다.

## 사용 방법

- 모니터 목록에서 모니터를 선택합니다.
- 해당 모니터의 프로필을 선택하거나 저장합니다.
- GPU에 따라 **감마 / 밝기 / 대비 / 채도 또는 디지털 바이브런스**를 조절합니다.
- **게임 자동**에서 게임 EXE별 프로필을 지정할 수 있습니다.
- **핫키**에서 프로필별 글로벌 단축키를 지정할 수 있습니다.
- **백업 / 불러오기** 기능으로 설정을 보관하고 복구할 수 있습니다.

설정은 실행 파일과 같은 폴더의 `GammaManager.ini`에 저장됩니다.

## GPU 색상 조절

- **NVIDIA:** `디지털 바이브런스`로 표시됩니다.
- **AMD:** 지원되는 경우 `채도`로 표시됩니다.
- 지원되지 않는 GPU에서는 해당 기능을 사용할 수 없습니다.

## 빌드

- 대상 프레임워크: **.NET Framework 4.7.2**
- 구성: **Release | Any CPU**
- `Prefer32Bit=false`
- Visual Studio에서 **솔루션 다시 빌드(Rebuild Solution)** 를 사용합니다.
- Visual Studio Publish / ClickOnce는 사용하지 않습니다.
- 일반적인 휴대형 WinForms 실행 파일로 빌드합니다.
