# 🖥️ Display Profile Manager v1.5.3[cite: 7]

> Windows용 모니터별 디스플레이 프로필 및 색상 설정 관리 도구[cite: 7]

[![Platform](https://img.shields.io/badge/Platform-Windows-0078D4?logo=windows&logoColor=white)](#)
[![Framework](https://img.shields.io/badge/.NET%20Framework-4.7.2-512BD4?logo=dotnet&logoColor=white)](#)
[![Version](https://img.shields.io/badge/Version-v1.5.3-2EA44F)](#)
[![License](https://img.shields.io/badge/License-CC0%201.0-9CF?logo=creativecommons&logoColor=white)](LICENSE.txt)

Display Profile Manager는 감마, 밝기, 대비, RGB 색상, 채도 같은 화면 설정을 모니터별 프로필로 저장하고 빠르게 적용할 수 있는 Windows용 디스플레이 제어 유틸리티입니다[cite: 7].

글로벌 핫키로 원하는 프로필을 즉시 적용하거나 **Apply / Toggle / Cycle** 방식으로 순환 적용할 수 있습니다[cite: 7]. 다중 모니터 환경에서는 모니터별 설정과 프로필을 독립적으로 관리합니다[cite: 7].

> ⚠️ 이 프로그램은 Windows 디스플레이 API, GPU API 및 지원되는 모니터의 DDC/CI를 사용하는 화면 설정 관리 도구입니다[cite: 7]. 모니터, GPU, 드라이버, HDR 설정 및 다른 화면 제어 프로그램의 상태에 따라 일부 기능은 제한되거나 충돌할 수 있습니다[cite: 7].

## 🚀 빠른 시작[cite: 7]

1. [Releases](https://github.com/SaPper0000/Display-Profile-Manager/releases)에서 최신 릴리즈를 다운로드합니다[cite: 7].
2. 원하는 폴더에 압축을 풉니다[cite: 7].
3. 아래 실행 파일을 실행합니다[cite: 7].

```text
Display-Profile-Manager-v1.5.3.exe
```

4. 상단 목록에서 설정할 모니터를 선택합니다[cite: 7].
5. GPU 색상 또는 모니터 하드웨어 값을 조절합니다[cite: 7].
6. 프로필 이름을 입력한 뒤 **저장**을 누릅니다[cite: 7].
7. 필요하면 **핫키 설정**에서 전역 단축키를 등록합니다[cite: 7].

별도의 설치 과정은 필요하지 않습니다[cite: 7].

## ✨ v1.5.3 주요 변경사항[cite: 7]

v1.5.3은 프로젝트 리브랜딩, 저작권 리소스 정비, 프로필 및 핫키 동기화 보강, DDC/CI 펌웨어 통신 안정화, 디스크 I/O 최적화, WMI 비관리 메모리 누수 방지, 다중 모니터 식별자 체계 강화를 적용한 종합 최적화 및 안정화 릴리즈입니다[cite: 7].

<!-- 변경사항 1: 프로젝트 리브랜딩 및 저작권 자산 정리 -->
<!-- ----------------------------------------------------------------- -->
### 🏷️ 프로젝트 리브랜딩 및 저작권 자산 정리
- **프로젝트 명칭 변경:** 기존 `Tarkov Gamma Manager`에서 특정 게임에 국한되지 않고 범용적으로 활용할 수 있는 `Display Profile Manager`로 정식 리브랜딩되었습니다[cite: 1, 7]. 기존 데이터 폴더(`%LOCALAPPDATA%\TarkovGammaManager`)와의 자동 마이그레이션이 완벽히 지원됩니다[cite: 1, 7].
- **저작권 침해 우려 리소스 전면 교체:** 타르코프 등 게임 관련 저작권 침해 소지가 있는 모든 그래픽/이미지 자산을 완전히 제거하고, 기본 자체 제작 고양이 배너(`DefaultCatBanner.png`) 및 사용자 커스텀 이미지 등록 기능으로 대체되었습니다[cite: 1, 7].

<!-- ----------------------------------------------------------------- -->
<!-- 변경사항 2: 프로필 공유 체계 및 식별자 -->
<!-- ----------------------------------------------------------------- -->
### 📦 프로필 공유 체계 및 다중 모니터 식별 강화
- **불변 하드웨어 식별자(`hardwareId`) 직렬화:** 프로필 내보내기/가져오기(Export/Import) 시 `hardwareId` 필드를 포함하도록 개선하여, 동일 모델 듀얼/트리플 모니터 환경에서도 타깃 모니터를 정확히 구분합니다[cite: 1, 2].
- **구버전 프로필 코드 완벽 호환:** 구버전(`v1.5`) 및 신버전(`v1.5.3`) 프로필 코드 포맷을 자동 감지하여 오류 없이 안전하게 가져오도록 하위 호환성을 보장합니다[cite: 2].

<!-- ----------------------------------------------------------------- -->
<!-- 변경사항 3: DDC/CI 하드웨어 통신 -->
<!-- ----------------------------------------------------------------- -->
### ⚡ DDC/CI 하드웨어 통신 및 안정성 개선
- **펌웨어 오차 허용치 완화 및 쓰기 우선 인정:** 일부 모니터 펌웨어의 고유 오차(±5)로 인해 읽기 검증이 실패하더라도 Win32 쓰기 API가 성공했을 경우 핸들을 불필요하게 재생성하지 않고 정상 적용으로 처리합니다[cite: 4, 5].
- **개별 밝기/대비 검증 오차 보정:** 통합 쓰기뿐만 아니라 개별 밝기/대비 슬라이더 조작 시에도 검증 허용치를 일관되게 적용하여 깜빡임과 딜레이를 개선했습니다[cite: 4, 5].
- **안전한 구형 핸들 정리:** DDC/CI 핸들 갱신 시 진행 중인 I/O 작업 완료 후 구형 핸들을 정리하여 핸들 충돌 및 무효 핸들 접근 위험을 제거했습니다[cite: 7].

<!-- ----------------------------------------------------------------- -->
<!-- 변경사항 4: 디스크 I/O 및 INI 캐시 -->
<!-- ----------------------------------------------------------------- -->
### 🚀 디스크 I/O 및 INI 캐시 최적화
- **슬라이딩 디바운스(Sliding Debounce) 적용:** 슬라이더를 연속 드래그할 때 매 변경마다 디스크에 접근하지 않고, 조작이 끝난 후 1회만 원자적으로 저장하도록 지연 타이머 갱신 구조로 최적화했습니다[cite: 3, 4].
- **백업 즉시 동기화:** 프로필 백업 저장 시 메모리 캐시를 먼저 디스크에 강제 플러시(`iniFile.Flush()`)한 뒤 복사하여 최신 설정 누락을 원천 차단했습니다[cite: 4, 5].
- **원자적 파일 교체:** 임시 파일과 `File.Replace` 원자적 치환 기법을 적용하여 비정상 종료 시 설정 파일 손상 가능성을 방지했습니다[cite: 7].

<!-- ----------------------------------------------------------------- -->
<!-- 변경사항 5: 메모리 관리 및 WMI -->
<!-- ----------------------------------------------------------------- -->
### 🧹 메모리 관리 및 WMI 누수 차단
- **WMI 미사용 인스턴스 즉시 해제:** 노트북/내장 화면 밝기 탐색 시 타깃과 일치하지 않는 `ManagementObject`를 즉시 `Dispose()` 처리하여 WMI 핸들 및 비관리 메모리 누수를 해결했습니다[cite: 2, 4].
- **이중 해제 예외 방지:** WMI 대체 인스턴스 교체 시 `null` 초기화를 통해 다중 `Dispose` 예외 발생을 방지했습니다[cite: 4, 5].
- **미사용 플래그 및 중복 검사 코드 정리:** 컴파일 경고를 유발하던 미사용 필드를 제거하고, 복원 루틴 내 중복 유효성 검사 코드를 정리했습니다[cite: 2, 3].

<!-- ----------------------------------------------------------------- -->
<!-- 변경사항 6: 글로벌 핫키 및 UI 연동 -->
<!-- ----------------------------------------------------------------- -->
### ⌨️ 글로벌 핫키 및 UI 연동 고도화
- **프로필 콤보박스 선택 동기화:** 핫키로 프로필을 적용할 때 모니터 접두사(예: `모니터명: `) 유무와 관계없이 메인 화면의 프로필 콤보박스가 정상적으로 선택 동기화되도록 수정했습니다[cite: 4, 5].
- **초기화 OSD 다국어 지원:** 단일/전체 디스플레이 초기화 핫키 입력 시 현재 언어 설정(한국어/English)에 맞춰 OSD 메시지가 올바르게 출력됩니다[cite: 4, 5].
- **핫키 ID 카운터 초기화:** 핫키 재등록 시 ID 카운터를 초기화하여 정수 오버플로우 가능성을 제거했습니다[cite: 7].
- **연쇄 이벤트 차단:** 채도 슬라이더 변경 시 텍스트 상자 재진입 방지 가드를 보강하여 불필요한 2중 호출을 방지했습니다[cite: 4, 5].

### ⌨️ 글로벌 핫키[cite: 7]

- **Apply:** 핫키 입력 시 지정된 프로필을 즉시 적용합니다[cite: 7].
- **Toggle:** 첫 입력에는 프로필을 적용하고, 다시 입력하면 적용 전 상태로 복귀합니다[cite: 7].

- **전체 초기화:** 연결된 모든 모니터의 화면 설정을 즉시(0ms) 초기화합니다[cite: 7].
- **Win 키 조합:** `Win + 키` 형태의 핫키 조합도 지원합니다[cite: 7].

### 🔄 원본 상태 복구[cite: 7]

프로그램은 실행 시점의 디스플레이 상태를 보관하고, 초기화 또는 비정상 종료 상황에서 가능한 범위 내에서 원본 상태를 복구하도록 설계되어 있습니다[cite: 7].

다만 Windows, GPU 드라이버, HDR, 모니터 펌웨어, 다른 디스플레이 제어 프로그램 등의 영향으로 모든 환경에서 완전한 복구를 보장할 수는 없습니다[cite: 7].

<!-- ----------------------------------------------------------------- -->
<!-- 안정성 2: 사용 시 주의사항 -->
<!-- ----------------------------------------------------------------- -->
### ⚠️ 사용 시 주의[cite: 7]

- 중요한 프로필은 변경 전 **백업**을 권장합니다[cite: 7].
- 가능하면 동시에 하나의 디스플레이 제어 프로그램만 실행하세요[cite: 7].
- 외장 모니터 하드웨어 제어는 DDC/CI를 지원하고 활성화한 환경에서만 정상 동작합니다[cite: 7].
- HDR, 야간 모드, GPU 제어판의 색상 설정 등이 프로그램 값과 충돌하거나 설정을 덮어쓸 수 있습니다[cite: 7].
- 게임 또는 전체 화면 앱에서 글로벌 핫키가 동작하지 않는다면 프로그램을 **관리자 권한으로 실행**해 보세요[cite: 7].

## 💾 백업 및 복원[cite: 7]

**백업** 기능은 저장된 프로필, 핫키 및 프로그램 설정을 INI 파일로 저장합니다[cite: 7].

백업 파일명 형식[cite: 7]:

```text
Display-Profile-Manager-Backup-YYYYMMDD-HHMMSS.ini
```

**불러오기** 기능은 백업 파일로 현재 설정을 복원합니다[cite: 7]. 복원 전 현재 설정은 `.pre-restore` 파일로 자동 보관되며, 복원 후 적용을 위해 프로그램이 다시 시작됩니다[cite: 7].

<!-- ----------------------------------------------------------------- -->
<!-- 설치 및 데이터 저장 폴더 구조 -->
<!-- ----------------------------------------------------------------- -->
## 📁 설치 및 데이터 저장 위치[cite: 7]

별도의 설치 과정이 필요 없는 포터블 실행 파일입니다[cite: 7].

모든 설정, 백업, 로그, 사용자 이미지는 다음 폴더에 저장됩니다[cite: 7].

```text
%LOCALAPPDATA%\DisplayProfileManager
├─ config\  (GammaManager.ini 설정 파일)
├─ state\   (시작 시점 화면 상태 백업)
├─ logs\    (DisplayProfileManager-YYYY-MM-DD.log)
├─ backup\  (수동 프로필 백업)
└─ images\  (custom-banner.png 사용자 이미지)
```

프로그램 우측 패널의 **📁 설정 / 로그 폴더 열기** 버튼을 누르면 이 폴더가 바로 열립니다[cite: 7].

<!-- 구버전 설정 자동 이전 -->
<!-- ----------------------------------------------------------------- -->
### 🔁 이전 버전 설정 이전[cite: 7]

이전 버전의 설정이 아래 위치에 있다면[cite: 7]:

```text
%LOCALAPPDATA%\TarkovGammaManager
```

새 설정 폴더가 비어 있을 때 설정, 프로필, 핫키, 로그, 백업, 사용자 이미지를 새 위치로 자동 복사합니다[cite: 7].

기존 폴더는 자동으로 삭제하지 않으므로 백업으로 남아 있습니다[cite: 7].
