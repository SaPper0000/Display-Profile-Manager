
# Tarkov Gamma Manager v1.5.0

> ## ⚠️ 관리자 권한 실행
> **게임을 실행한 상태에서 글로벌 핫키를 사용하려면 프로그램을 관리자 권한으로 실행해야 합니다.**

Escape from Tarkov 할 때 **감마 / 밝기 / 대비 / 채도 같은 화면 설정을 프로필로 묶어서 편하게 바꾸는 Windows용 프로그램**입니다.

게임이 활성화되면 자동으로 프로필을 적용할 수도 있고, 글로벌 핫키로 원하는 프로필을 바로 적용하거나 Toggle로 잠깐 바꿨다가 이전 상태로 돌아올 수도 있습니다.

여러 대의 모니터를 사용하는 환경도 고려해서 **모니터별 설정과 프로필**을 관리할 수 있습니다.

> ⚠️ 이 프로그램은 Battlestate Games 또는 Escape from Tarkov의 공식 프로그램이 아닙니다.

## ✨ v1.5.0 주요 변경사항

이번 버전은 **"성능 최적화와 쾌적한 사용 경험(UX)"**에 모든 초점을 맞추었습니다. 
프로그램이 차지하는 시스템 자원을 극한으로 줄이고, 다중 모니터 환경에서 발생하는 딜레이를 제거했으며, 원할 때 즉시 원래 화면으로 돌아갈 수 있는 전용 핫키와 소소한 커스텀 기능을 추가했습니다.

### 🚀 성능 및 최적화 (성능 렉 제로화)

- **슬라이더 렉 완전 해결 (비동기 & 디바운싱):** 밝기/대비 슬라이더를 마우스로 마구 드래그할 때 모니터 통신 병목으로 인해 발생하던 심각한 UI 끊김 현상(Freezing)을 백그라운드 처리로 완벽히 해결했습니다.
- **INI 파일 100% 메모리 캐싱:** 디스크(SSD/HDD) 입출력 병목을 제거하여, 핫키나 Game Auto가 동작할 때 프로필을 읽어오며 발생하던 미세한 잔렉을 없앴습니다.
- **백그라운드 RAM 최적화:** 창을 최소화하거나 트레이 아이콘으로 숨길 때, 사용하지 않는 메모리를 즉시 Windows에 반납하여 메모리 누수를 방지합니다. (점유율 1~5MB 수준 유지)
- **WMI 자원 누수 방지 (노트북 모니터):** 노트북 내장 모니터 밝기를 조절할 때마다 무거운 WMI 객체를 켰다 끄던 방식을 1회 연결 후 재사용하도록 변경하여 CPU 낭비를 줄였습니다.

### 🛡️ 프로세스 감지 권한 최소화 (안전성 강화)

- **Native API 방식 적용:** 타르코프 등 게임 실행을 감지할 때, 기존의 무거운 .NET 내장 함수(`Process.GetProcessById`) 대신, 윈도우 커널이 제공하는 **가장 낮은 수준의 조회 권한(`PROCESS_QUERY_LIMITED_INFORMATION`)**만을 사용하도록 변경했습니다. 
- 게임의 메모리나 스레드에 전혀 간섭하지 않으므로, BattlEye 등 안티치트 프로그램에게 "안전한 유틸리티"로 인식될 수 있도록 구조를 모범적으로 개선했습니다.

### 🔄 전체 및 개별 모니터 강제 초기화(Hard Reset) 핫키

- 화면이 꼬이거나 설정이 마음에 안 들 때, 언제든지 **버튼 한 번으로 원본 상태로 복구할 수 있는 "패닉 버튼" 기능**을 핫키에 추가했습니다.
- **전체 디스플레이 초기화** 핫키는 물론, **연결된 모니터 각각의 단독 초기화 핫키**를 따로 설정할 수 있어 다중 모니터 사용자의 편의성을 극대화했습니다.

### 🎨 테마 이미지 변경 기능 (Killa & Tagilla)

- 메인 화면 우측의 데코레이션 이미지를 기존의 밋밋한 모니터 화면에서, 많은 유저들이 좋아하는 귀여운 **Killa & Tagilla 팬아트 밈 이미지**로 바꿀 수 있는 콤보박스 옵션을 추가했습니다.
- 선택된 이미지는 INI에 저장되어 다음 실행 시에도 유지됩니다.

### 🖥️ 다중 모니터 병렬 제어

- 듀얼 모니터 이상의 환경에서 프로필을 바꿀 때, 기존처럼 1번 모니터가 다 바뀔 때까지 2번 모니터가 기다리던(순차적) 문제를 해결했습니다. 
- 모니터마다 독립적인 락(Lock)을 부여하여 **여러 대의 모니터 화면이 동시에 빠릿하게 변경**됩니다.
- 모니터 하드웨어 통신 실패 시, 상세한 Win32 Error 코드를 로그 파일에 남겨 오류 추적이 쉬워졌습니다.

## 🔀 프로필 우선순위 정리

여러 경로에서 프로필이 동시에 적용될 수 있기 때문에, 현재 어떤 상태가 우선되는지 명확하게 관리합니다.

실제 프로필 적용 우선순위는:

```text
수동 핫키 / Toggle
      ↓
Game Auto
      ↓
Base / 원래 상태

```

`Hard Reset`은 위 우선순위에 끼는 프로필이 아니라, **언제든 현재 상태를 정리하고 프로그램 시작 당시의 원본 상태로 복구하는 별도의 강제 초기화 기능**입니다.

## 🎮 주요 기능

### 게임 자동 프로필

지정한 게임 프로세스가 활성화되면 연결된 프로필을 자동으로 적용합니다.
게임 포커스를 벗어나면 이전 상태를 복구하고, 다시 게임으로 돌아오면 Game Auto 프로필을 적용합니다.

Game Auto 감지는 350ms 주기 폴링이 아니라 Windows의 Foreground Window 이벤트(`SetWinEventHook / EVENT_SYSTEM_FOREGROUND`)를 사용합니다. 즉, 활성 창이 변경될 때만 현재 프로세스를 확인합니다.

### ⌨️ 글로벌 핫키 / Apply / Toggle

각 프로필에 글로벌 핫키를 지정할 수 있습니다.

**Apply**

```text
핫키 입력 → 지정한 프로필 적용

```

**Toggle**

```text
첫 번째 입력 → 프로필 적용
두 번째 입력 → Toggle 이전 상태 복구

```

Game Auto가 이미 A 프로필을 적용한 상태에서 B Toggle을 사용한 경우에도, B를 끄면 무조건 A로 돌아가는 방식이 아니라 **Toggle을 켜기 전에 캡처한 상태**를 기준으로 복구합니다.

### 🖥️ 모니터별 디스플레이 설정

여러 대의 모니터를 사용하는 환경에서도 모니터별로 설정을 관리할 수 있습니다.
프로필에는 다음과 같은 설정을 저장할 수 있습니다.

* Gamma
* 밝기
* 대비
* AMD Saturation
* NVIDIA Digital Vibrance
* 지원 모니터의 DDC/CI 밝기 / 대비

### 🟥 AMD - Saturation / 🟩 NVIDIA - Digital Vibrance

지원되는 AMD 환경에서는 디스플레이별 **Saturation(채도)** 을 조절할 수 있습니다.
NVIDIA 환경에서는 **Digital Vibrance(디지털 바이브런스)** 를 조절할 수 있습니다.

### 🌐 한국어 / English

프로그램 내부에서 한국어와 English를 선택할 수 있습니다. (실행 중 즉시 전환 및 상태 유지)

## 🔒 안티치트 관련 안내

이 프로그램은 게임 내부 기능을 조작하는 프로그램이 아니라 **Windows 디스플레이 설정과 포그라운드 게임 감지를 이용하는 모니터 프로필 관리 도구**입니다.

현재 소스에는 다음과 같은 게임 개입 기능이 포함되어 있지 않습니다.

* 게임 메모리 읽기 / 쓰기
* DLL Injection
* 게임 DLL Hooking
* 커널 드라이버
* 게임 파일 수정
* 패킷 조작
* 게임 메모리 스캔
* 게임 화면 캡처

Game Auto는 Windows의 foreground-window 이벤트와 일반적인 프로세스 정보를 사용해 **어떤 프로그램이 활성화되어 있는지 확인하고 프로필을 적용**합니다.

> ⚠️ BattlEye를 포함한 안티치트의 탐지 방식과 정책은 개발자가 통제할 수 없으며 향후 변경될 수 있습니다. 따라서 어떤 환경에서도 "절대 탐지되지 않는다"고 보증하지는 않습니다.

## 📦 설치 및 실행

별도의 설치 프로그램 없이 사용하는 포터블 방식입니다.

1. GitHub Releases에서 원하는 버전의 ZIP을 다운로드합니다.
2. 압축을 해제합니다.
3. `Tarkov-Gamma-Manager-v1.5.0-Korean-English.exe`를 실행합니다.
4. 처음 사용하는 경우 모니터 / 프로필 / Game Auto / 핫키 설정을 확인합니다.

게임 실행 중 글로벌 핫키를 사용하려면 프로그램을 **관리자 권한으로 실행**해야 합니다.

## 🛠️ 직접 빌드하기

Visual Studio에서 솔루션을 열어 직접 빌드할 수 있습니다.

* 대상 프레임워크: **.NET Framework 4.7.2**
* 구성: **Release**
* 플랫폼: **Any CPU**
* `Prefer32Bit=false`

솔루션 파일:

```text
Tarkov-Gamma-Manager-v1.4.sln

```

일반 사용자는 직접 빌드하지 않고 GitHub Releases에서 제공되는 배포 파일을 사용하는 것을 권장합니다.

## 📁 로그 / 설정 파일

프로그램 설정은 기본적으로 실행 파일 폴더의 INI 파일에 저장됩니다. (v1.5.0부터 캐싱을 통해 접근 속도가 최적화되었습니다.)
로그 기능을 켠 경우 로그는 다음 폴더에 생성됩니다.

```text

└─ TarkovGammaManager-YYYY-MM-DD.log

```

## ⚠️ 주의사항

* AMD Saturation / NVIDIA Digital Vibrance는 GPU 및 드라이버 환경에 따라 지원 여부가 달라질 수 있습니다.
* 일부 모니터에서는 DDC/CI를 통한 밝기 / 대비 읽기 또는 변경이 제한될 수 있습니다.
* 업데이트 전에는 기존 프로필을 백업하는 것을 권장합니다.
* 이 프로그램은 Battlestate Games의 공식 프로그램이 아닙니다.
* 안티치트의 정책이나 탐지 방식은 개발자가 통제할 수 없으므로 게임 이용 제한이 발생하지 않는다고 보증할 수 없습니다.
