# 🖥️ Display Profile Manager v1.5.3-2

<img width="1082" height="752" alt="image" src="https://github.com/user-attachments/assets/5953b4ca-a9a3-47bd-92ec-62c34a986976" />


> Windows용 모니터별 디스플레이 프로필, 게임 자동 감지 및 색상 설정 관리 도구

[![Platform](https://img.shields.io/badge/Platform-Windows-0078D4?logo=windows&logoColor=white)](#)
[![Framework](https://img.shields.io/badge/.NET%20Framework-4.7.2-512BD4?logo=dotnet&logoColor=white)](#)
[![Version](https://img.shields.io/badge/Version-v1.5.3--2EA44F)](#)
[![License](https://img.shields.io/badge/License-CC0%201.0-9CF?logo=creativecommons&logoColor=white)](LICENSE.txt)

Display Profile Manager는 감마, 밝기, 대비, RGB 색상, 채도 같은 화면 설정을 모니터별 프로필로 저장하고 빠르게 적용할 수 있는 Windows용 디스플레이 제어 유틸리티입니다.

게임 실행을 자동으로 감지해 전용 프로필을 켜주거나, 글로벌 핫키(**Apply / Toggle / Cycle**)를 통해 즉각적인 프로필 전환이 가능합니다. 또한, 커스텀 이미지 비교 기능을 통해 어두운 맵과 밝은 맵을 실시간으로 대조하며 최적의 공용 프로필을 쉽게 튜닝할 수 있습니다.

> ⚠️ 이 프로그램은 Windows 디스플레이 API, GPU API 및 모니터 DDC/CI를 사용합니다. 드라이버 환경, HDR 활성화 여부, 타사 화면 제어 프로그램에 따라 일부 기능 동작이 달라질 수 있습니다.

## 🚀 빠른 시작

1. [Releases](https://github.com/SaPper0000/Display-Profile-Manager/releases)에서 최신 릴리즈 압축 파일을 다운로드합니다.
2. 원하는 위치에 압축을 해제합니다.
3. `Display-Profile-Manager-v1.5.3-2.exe`를 실행합니다.
4. 상단 모니터 목록에서 제어할 디스플레이를 선택합니다.
5. 슬라이더로 원하는 색상 및 하드웨어 값을 조절한 뒤 프로필을 저장합니다.
6. 필요에 따라 **게임 자동 적용**을 연결하거나 **글로벌 핫키**를 등록합니다.

별도의 설치 과정이 필요 없는 포터블 실행 파일입니다.

### 🛠️ v1.5.3-2 핫픽스 및 최적화 (Hotfix & Optimization)
- **창 항상 위로 & 내리기/숨기기 동작 분리:**
  - `창을 맨위로` **체크 ON**: 항상 최상단 표시(`TopMost = true`), 버튼이 `숨기기`로 표시되며 클릭 시 **알림 영역(시스템 트레이)으로 숨김** 처리됩니다.
  - `창을 맨위로` **체크 OFF**: 일반 창(`TopMost = false`)으로 동작, 버튼이 `내리기`로 표시되며 클릭 시 알림 영역 대신 **Windows 작업표시줄로 안전하게 최소화**됩니다.
  - 기존 `Window_Resize` 이벤트에서 무조건 `Hide()`를 호출하던 버그를 해결하여 작업표시줄 최소화 동작을 완벽히 복원했습니다.
- **동일 모델 다중 모니터 고유 EDID 시리얼 넘버 1:1 매칭:**
  - `MonitorIdentity.Read()`에서 동일 모델 모니터의 레지스트리 인스턴스를 탐색할 때, 장치의 `hardwareId`에 일치하는 서브키를 우선 탐색하여 **각 모니터의 실제 고유 EDID Serial을 정확히 추출**하도록 개선했습니다. (PC 재부팅/절전모드 복귀 시 프로필 뒤바뀜 원천 방지)
- **동일 모델 다중 모니터 프로필 콤보박스 및 게임 자동 매칭 분리:**
  - 메인 UI `initPresets`, 트레이 메뉴 `initTrayMenu`, 게임 자동 감지 `TryGetAutoMapping`에서 동일 모델 2대 이상 연결 시(`hasDuplicateModel`), `baseDisplayName` 와일드카드 매칭을 차단하고 `(#1)`, `(#2)`가 포함된 **정확한 `displayName` 또는 `monitorKey`로만 매칭**되도록 하여 다른 모니터의 프로필이 섞이거나 잘못 적용되는 문제를 방지했습니다.
- **NumericUpDown 스핀 버튼(▲/▼ 화살표) 클릭 및 수치 동기화 완벽 수정:**
  - 증감 화살표(▲/▼) 클릭 시 WinForms의 지연 텍스트 대신 정밀한 내부 `.Value`를 직접 읽도록 개선하여, 버튼 클릭 즉시 슬라이더 및 화면 설정(감마/대비/밝기/채도)에 0.05/0.01 단위로 정확하고 부드럽게 반영되도록 해결했습니다. (수동 텍스트 타이핑 입력은 Enter/포커스 아웃 시에만 파싱되도록 역할 명확히 분리)
- **핫키 키 꾹 누름(Auto-repeat) 및 고속 연타 시 프로그램 프리징 & 상태 불일치 완벽 해결:**
  - 핫키를 꾹 누르고 있을 때 Windows에서 초당 약 30회 발생하는 `WM_HOTKEY` 폭주를 차단하기 위해 **180ms 쿨다운 스로틀(Throttle)**을 적용했습니다.
  - 토글 스냅샷(`CaptureMonitorState`) 시 UI 스레드를 100~200ms 블로킹하던 동기식 DDC/CI 하드웨어 통신을 제거하고, 메모리 캐시값을 0ms 즉시 스냅샷하도록 최적화했습니다.
  - 소프트웨어 감마(`Gamma.SetGammaRamp`)를 토글 끄기/복원(`RestoreMonitorState`) 및 초기화 시에도 켜기와 동일하게 **동기식(0ms) 즉시 반영**하여 화면과 OSD가 어긋나는 레이스 컨디션을 원천 차단했습니다.
  - 토글 반복 입력 시 `ReturnState`가 켜져 있던 프로필로 오염되어 한 값에 고정되던 문제를 해결하여, 키를 오래 꾹 누르고 있어도 **[프로필 ↔ 기본값]이 끝까지 부드럽게 교차 반복**되며 손을 떼는 순간 OSD와 실제 화면이 100% 일치하도록 완성했습니다.
- **트레이 최소화 상태 중복 실행 및 재시작 Mutex 인계 개선:**
  - `RegisterWindowMessage` 기반 IPC 브로드캐스트를 도입하여 트레이 최소화 상태에서 재실행 시 기존 창이 즉시 화면 전면으로 복원되도록 개선했습니다.
  - 백업 복원 등으로 `--restart` 인자 실행 시 이전 인스턴스의 단일 인스턴스 Mutex가 정상 해제될 때까지 최대 2.5초 대기 후 소유권을 안전하게 인계받도록 처리했습니다.
- **CancellationTokenSource 및 GDI 리소스 누수 차단:**
  - `OSDForm`의 `_fadeCts`, `Window.Lifecycle`의 `_displayChangeCts`, `IniFile`의 `_saveCts` 라이프사이클에 명시적 `Dispose()`를 적용하여 CTS 핸들 누수를 차단했습니다.
  - 테마 전환 및 단축키 설정 안내 문구의 GDI Font 객체를 재사용하도록 캐싱하여 GDI 핸들 낭비를 제거했습니다.
- **순환 핫키 엔진 및 UI 플래그 보호 최적화:**
  - 순환 핫키 delegate 내부에서 `sections` 루프마다 중복 계산되던 `targetKey`, `hasDuplicateModel` 등의 LINQ 연산을 루프 밖으로 끌어올려 O(N×M) → O(N+M) 성능을 최적화했습니다.
  - UI 동기화 중 `disableChangeFunc`를 `try/finally`로 보호하여 예외 발생 시 UI 조작 잠금 현상을 방지했습니다.
  - 메인 화면 프로필 선택 드롭다운(`comboBoxPresets`)의 최상단에 **`[기본값]` / `[Default]` 항목을 항상 고정 배치**하여, 초기화 버튼을 누르지 않고도 드롭다운에서 즉시 기본 모니터 상태로 전환할 수 있도록 직관성을 강화했습니다. 초기화 버튼 클릭 및 토글 해제 시에도 드롭다운이 `[기본값]`으로 깔끔하게 자동 선택됩니다.
- **프로필 관리자 예약어 검증 및 가져오기 시 대상 모니터 선택 지원:**
  - 프로필 이름 변경 시 `__CYCLE_`, `AutoGame_` 예약어 충돌 방지 검사를 추가했습니다.
  - 프로필 공유 코드를 붙여넣기(가져오기)할 때, **현재 PC에 연결된 모니터 중 어느 모니터에 적용할지 직접 선택**할 수 있는 대화상자를 추가하여 타사 모니터 프로필이나 다른 모니터로의 프로필 복제를 완벽하게 지원합니다.
  - 프로필 내보내기/가져오기 시 `monitorKey` 필드를 포함(포맷 `v1.5.3-2`)하여 고유 모니터 식별 및 구버전 하위 호환성을 유지했습니다.
- **Logger 디스크 I/O 최적화:**
  - 매 로그 기록마다 발생하던 동기식 파일 크기 및 존재 여부 검사를 메모리 캐싱 방식으로 전환하여 로깅 오버헤드를 대폭 절감했습니다.

## ✨ v1.5.3 주요 변경사항

v1.5.3은 게임 자동 감지 연동 추가, 커스텀 이미지 비교 튜닝 기능 도입, 프로젝트 리브랜딩, DDC/CI 통신 안정화, 디스크 I/O 최적화 및 비관리 메모리 누수 방지 처리가 적용된 종합 안정화 업데이트입니다.

### 🎮 게임/프로세스 자동 감지 프로필 연동
- **게임 실행 시 자동 프로필 적용:** 특정 게임 실행 파일(`.exe`)을 등록해두면, 게임 창 활성화 감지 시 지정된 화면 프로필로 즉시 전환됩니다.
- **종료 및 포커스 아웃 시 자동 복구:** 게임을 종료하거나 다른 창(Alt+Tab)으로 전환 시 실행 이전의 화면 설정값으로 안전하게 복원됩니다.
- **포커스 기반 지능형 토글 해제:** 게임 중 핫키 토글을 켰다가 바탕화면으로 나온 상태에서 토글을 꺼도, 현재 활성 창 상태를 감지하여 기본 화면으로 알맞게 복귀합니다.
- **백그라운드 감지 최적화:** `WINEVENT_OUTOFCONTEXT` 기반 비주입식 이벤트 알림을 사용하여 게임 프레임 드랍 및 CPU 점유율 오버헤드를 원천 차단했습니다.

### 🖼️ 인게임 맵 스크린샷 비교 & 공용 프로필 튜닝
- **커스텀 이미지 프리뷰 등록:** 사용자가 직접 캡처한 어두운 맵이나 야간 시간대 인게임 스크린샷을 프로그램 프리뷰 창에 등록할 수 있습니다.

### ⚡ DDC/CI 통신 및 다중 모니터 식별 개선
- **DDC/CI 펌웨어 오차 보정:** 모니터 펌웨어 고유 읽기 오차(±5) 발생 시에도 Win32 API 쓰기 성공 시 정상 적용으로 처리하여 깜빡임과 딜레이를 해소했습니다.
- **안전한 핸들 라이프사이클:** 진행 중인 I/O 완료 후 구형 핸들을 폐기하여 무효 핸들 접근 및 충돌을 방지했습니다.
- **불변 Hardware ID 직렬화:** 동일 모델의 다중 모니터 환경에서도 타깃 디스플레이를 명확히 구분하도록 프로필 Import/Export 체계를 보강했습니다.

### 🧹 성능 최적화 및 버그 수정
- **슬라이딩 디바운스(Debounce) I/O 최적화:** 슬라이더 조작 시 실시간 쓰기를 지연시키고 조작 완료 후 1회만 디스크에 기록하도록 개선했습니다.
- **원자적 파일 교체 & 백업 동기화:** 캐시 플러시 후 임시 파일 치환 방식을 적용해 비정상 종료 시에도 설정 파일 손상을 방지합니다.
- **WMI 비관리 메모리 누수 해결:** 타깃 외 인스턴스 즉시 `Dispose` 처리 및 이중 해제 방지 로직을 적용했습니다.
- **핫키 입력 시 모니터 UI 자동 전환:** 다중 모니터 환경에서 단축키 입력 시 현재 창의 모니터 선택 드롭다운과 프로필 콤보박스, 슬라이더 수치가 해당 모니터 상태로 자동 동기화됩니다.

### 🖼️ 화면 비교 튜닝 & 커스텀 이미지
- 직접 캡처한 어두운 맵/야간 맵 스크린샷을 배너 영역에 등록 (PNG, JPG, BMP, GIF 지원)
- 주간 인게임 화면과 야간 프리뷰 이미지를 동시에 보면서 균형 잡힌 화면 설정 조율
- 이미지 끄기 옵션 및 프로그램 재시작 후에도 선택 이미지 유지

<!-- ----------------------------------------------------------------- -->
<!-- 핵심 기능 3: GPU 및 하드웨어 화면 제어 -->
<!-- ----------------------------------------------------------------- -->
### 🎨 디스플레이 색상 및 하드웨어 제어

| 제어 항목 | 설명 | 제어 방식 |
|---|---|---|
| 감마 / 밝기 / 대비 | 화면의 감마 곡선, 밝기 오프셋, 대비 제어 | GPU API / Direct3D |
| RGB 개별/전체 조절 | 색상 채널별 독립 또는 통합 밸런스 조정 | GPU LUT Table |
| 채도 (Saturation) | NVIDIA Digital Vibrance / AMD 채도 제어 | 제조사 전용 API |
| 외장 모니터 밝기/대비 | 모니터 패널의 하드웨어 밝기/대비 직접 제어 | DDC/CI |
| 노트북 내장 화면 밝기 | 노트북 패널 밝기 제어 | WMI |

<!-- ----------------------------------------------------------------- -->
<!-- 핵심 기능 4: 글로벌 핫키 -->
<!-- ----------------------------------------------------------------- -->
### ⌨️ 글로벌 핫키

- **Apply:** 단축키로 특정 프로필 즉시 적용
- **Toggle:** 단축키 입력마다 [프로필 적용 ↔ 이전 상태] 토글
- **Cycle:** 지정된 프로필 목록을 순차적으로 순환 적용
- **전체/개별 초기화:** 단일 모니터 또는 연결된 전 모니터 0ms 즉시 리셋
- **Windows 키 지원:** `Win + 키` 조합의 단축키 등록 지원

<!-- ----------------------------------------------------------------- -->

<!-- ----------------------------------------------------------------- -->
### 📋 프로필 관리 및 편의 기능

- 클립보드를 통한 프로필 Import / Export (Hardware ID 식별자 지원)
- 프로필 순서 이동, 정렬, 중복 이름 검증
- 다국어 OSD 알림 팝업 (위치, 글자 색상, 크기, 표시 시간 커스텀)
- 라이트 / 다크 테마 완벽 지원

## 📁 데이터 저장 위치

모든 설정, 백업, 로그, 이미지는 로컬 앱데이터 폴더에 안전하게 격리 보관됩니다.

```text
%LOCALAPPDATA%\DisplayProfileManager
├─ config\  (GammaManager.ini 메인 설정)
├─ state\   (시작 시점 원본 화면 백업)
├─ logs\    (프로그램 구동 로그)
├─ backup\  (수동 프로필 백업 INI)
└─ images\  (custom-banner.png 사용자 이미지)
```

> 💡 프로그램 내 **📁 설정 / 로그 폴더 열기** 버튼으로 즉시 접근할 수 있습니다.

### 동일 모델 모니터 2대 지원
프로필 식별은 가능한 경우 EDID Serial 기반 `monitorKey`를 사용합니다. 동일 모델 모니터를 2대 연결해도 각 모니터의 프로필, 토글, 게임 자동 적용 상태를 별도로 유지하도록 구성되어 있습니다. EDID Serial을 제공하지 않는 모니터는 Windows PNP Device ID를 사용하고, 현재 세션에서 동일 값까지 겹치면 `DISPLAY` 링크를 런타임 보조키로 사용합니다.
