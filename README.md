# 🖥️ Display Profile Manager v1.5.6


<img width="1082" height="752" alt="image" src="https://github.com/user-attachments/assets/7823a0d5-531a-4340-adea-d94f58815e9d" />


> Windows용 모니터별 디스플레이 프로필, 게임 자동 감지, 즉시 볼륨 전환, 화면 필터 스크린샷, 동영상 프로필 필터 및 색상 설정 관리 도구

[![Platform](https://img.shields.io/badge/Platform-Windows-0078D4?logo=windows&logoColor=white)](#)
[![Framework](https://img.shields.io/badge/.NET%20Framework-4.7.2-512BD4?logo=dotnet&logoColor=white)](#)
[![Version](https://img.shields.io/badge/Version-v1.5.6-2EA44F)](#)
[![License](https://img.shields.io/badge/License-CC0%201.0-9CF?logo=creativecommons&logoColor=white)](LICENSE.txt)

Display Profile Manager는 감마, 밝기, 대비, RGB 색상, 채도, 하드웨어 DDC/CI 같은 화면 설정을 모니터별 프로필로 저장하고 빠르게 적용할 수 있는 Windows용 디스플레이 & 오디오 통합 제어 유틸리티입니다.

게임 실행을 자동으로 감지해 전용 화면 프로필을 켜주거나, 글로벌 핫키(**Apply / Toggle / Cycle**)를 통해 즉각적인 프로필 전환이 가능합니다. 또한, 어두운 맵과 밝은 맵을 실시간으로 대조하며 최적의 공용 프로필을 튜닝하는 **커스텀 이미지 비교 기능**, 게임 및 작업 중 단축키 한 번으로 소리를 낮추거나 원하는 볼륨으로 토글하는 **즉시 볼륨 전환(Quick Volume Switch)**, 모니터에서 튜닝한 색감을 그대로 캡처하는 **화면 필터 스크린샷(Filtered Screenshot)**, 그리고 녹화 영상에 화면 튜닝 색감을 그대로 적용하는 **동영상 프로필 필터 적용** 기능을 제공합니다.

> ⚠️ 이 프로그램은 Windows 디스플레이 API, GPU API, 모니터 DDC/CI 및 Windows Core Audio API를 사용합니다. 드라이버 환경, HDR 활성화 여부, 타사 화면 제어 프로그램에 따라 일부 기능 동작이 달라질 수 있습니다.

## 🚀 빠른 시작

1. [Releases](https://github.com/SaPper0000/Display-Profile-Manager/releases)에서 최신 릴리즈 압축 파일을 다운로드합니다.
2. 원하는 위치에 압축을 해제합니다.
3. `Display-Profile-Manager-v1.5.6.exe`를 실행합니다.
4. 상단 모니터 목록에서 제어할 디스플레이를 선택합니다.
5. 슬라이더로 원하는 색상 및 하드웨어 값을 조절한 뒤 프로필을 저장합니다.
6. 필요에 따라 **게임 자동 적용**, **글로벌 핫키**, **즉시 볼륨 전환**, **화면 필터 스크린샷**, **동영상 프로필 필터**를 등록하여 사용합니다.

별도의 설치 과정이 필요 없는 포터블 실행 파일입니다.

## ✨ v1.5.6 릴리즈 변경 사항

### 🆕 새로운 기능 및 주요 개선
- **📸 화면 필터 스크린샷 (Filtered Screenshot) 엔진 탑재:**
  - 모니터에 적용된 감마, 대비, 밝기, 채도, 블랙 EQ(4대 모드), 색조 틴트, 하이라이트 가드를 **캡처 이미지에 그대로 입혀주는 전용 필터 캡처 엔진** 탑재
  - **자유로운 글로벌 핫키 커스터마이징:** 핫키 설정 창(`Hotkeys`) 및 스크린샷 전용 설정 창에서 원하는 단축키(예: `F11`, `Pause`, `NumPad *`, `Ctrl+Shift+S` 등)를 자유롭게 지정/해제 가능
  - **초고속 픽셀 LUT 파이프라인:** 1D 룩업 테이블(LUT) 및 최적화된 메모리 매핑을 통해 캡처 후 **5~15ms(0.01초 미만)** 이내로 고속 처리되어 고사양 게임(타르코프, 배그 등) 플레이 중에도 인게임 프레임 드랍 0%
  - **클립보드 즉각 복사:** 캡처 즉시 Windows 클립보드에 복사되어 디스코드, 카카오톡, 웹 브라우저 등에 **`Ctrl + V`로 즉시 붙여넣기 전송 가능**
  - **자동 파일 저장 지원:** 날짜/시간별 파일명(`Screenshot_YYYYMMDD_HHmmss.png`)으로 자동 보관, 무손실 PNG 및 고화질 JPG(95%) 선택 지원
  - **캡처 피드백:** 셔터 효과음 재생 및 화면 상단 OSD 팝업 알림 지원
  - **UI 대칭형 레이아웃 정돈:** 우측 기능 카드에 [📸 필터 스크린샷 설정] 버튼 추가 및 단축키 등록 상태 실시간 표시

- **🌑 블랙 이퀄라이저 (Black EQ) 커스텀 고도화 파라미터 추가:**
  - **색조 틴트 (Tint):** 중립(Neutral), 따뜻한 톤(Warm), 차가운 톤(Cold) 선택 지원
  - **눈부심 방지 가드 (Highlight Guard):** 0~100% 강도 조절로 밝은 조명/야외에서의 눈부심을 억제
  - **커스텀 피크 중심 (10% ~ 40%) & 대역폭 (1~5단계):** 사용자 환경에 맞춰 암부 부스트 지점과 범위를 세밀하게 커스터마이징 가능

- **📦 v1.5.6 확장 프로필 공유 지원:**
  - 클립보드 프로필 공유(`TGM-Profile|v1.5.6|...`) 시 고도화된 블랙 EQ 파라미터(틴트, 가드, 커스텀 피크/대역폭) 온전하게 보존
  - 이전 버전(v1.5.5, v1.5.4, v1.5.3 등) 프로필에 대한 완벽한 하위 호환 파싱 지원

### ⚡ 아키텍처 및 안정성 고도화 (엔지니어링 리팩토링)
- **🧱 ProfileData DTO 단일화 (Single Source of Truth):**
  - 감마, 대비, 밝기, 채도, DDC/CI, 블랙 EQ 등 15개 디스플레이 파라미터의 INI 저장 및 로드 로직을 `ProfileData` 클래스로 단일 캡슐화
  - `InitializeCurrentPresetState`, `EnsureDefaultProfile`, `buttonSave_Click`, `ApplyPreset`, `buttonUpdateDefault_Click` 전반의 **180줄 이상의 중복 코드 제거** 및 향후 기능 확장 시 버그 발생 확률 원천 차단
  - 문화권 소수점(콤마/점) 정규화 및 수치 범위 안전 클램핑(Clamping) 일원화
- **🔒 GameAuto 포그라운드 윈도우 후킹 레이스 컨디션 해결 (Atomic Interlocked):**
  - OS 레벨 `SetWinEventHook` 콜백 처리부에 `Interlocked.CompareExchange` 기반 원자적 진입 가드를 적용하여, 고속 창 전환(`Alt + Tab` 연타) 상황에서도 스레드 경합 없이 안정적인 프로필 전환 보장
- **🛡️ DDC/CI 하드웨어 통신 안정성 강화:**
  - I2C 버스 특성을 고려한 세대 토큰(Generation Token) 이중 검증(Double-check Lock) 유지 및 안전한 하드웨어 자원 라이프사이클 관리

### 📜 v1.5.4 릴리즈 주요 내용

### 🆕 새로운 기능 및 주요 개선
- **🔊 즉시 볼륨 전환 (Quick Volume Switch):**
  - 게임이나 작업 중 글로벌 단축키 한 번으로 마스터 볼륨, 현재 활성 창(게임), 또는 지정 프로그램 사운드를 즉각 원하는 볼륨(0~100%)으로 낮추고 다시 누르면 안정적으로 원래 볼륨으로 복원
  - **3가지 적용 모드 지원:** 전체 시스템(마스터/음소거 보존), 현재 활성 창(자동 감지 및 PID+이름 이중 타깃팅), 지정 프로그램(오디오 세션 직접 제어)
  - **상시 유지(Persistent) OSD:** 볼륨이 전환된 상태임을 계속 인지할 수 있도록 화면에 OSD를 상시 띄워두는 옵션 지원
- **🌑 블랙 이퀄라이저 (Black Equalizer) & 4대 알고리즘 모드:**
  - 밝은 영역(야외, 하늘, 조명)의 눈부심 없이 어두운 실내/그늘진 암부(0~35%)의 시인성만 핀셋으로 집중 부스트
  - FPS 표준 밸런스(Balanced Toe), 야간전(Deep Shadow), 정밀 분리형(Precision Spline), e스포츠 트루 블랙(True Black) 4가지 수학 곡선 모드 탑재
  - 실시간 2D 감마 커브 분석 및 0~10단계 계조 테스트 바로 모니터 최적 식별점 즉석 캘리브레이션 가능
- **🎨 확장 대비 (최대 10.00) 정식 지원:**
  - 기존 3.00 한계 클램핑을 해제하여 확장 대비 모드 사용 시 최대 10.00까지 고대비 감마 램프를 정상 생성 및 적용

### 🌑 블랙 이퀄라이저 (Black Equalizer / Black EQ)
- **암부 전용 비선형 부스트:** 일반 감마 조절과 달리 밝은 영역의 눈부심 없이 어두운 그늘과 실내 암부(0~35%)의 시인성만 핀셋처럼 집중 향상
- **4대 알고리즘 모드 지원:**
  - **FPS 표준 밸런스:** 게이밍 표준의 균일하고 부드러운 3차 토우 곡선 (색 뭉침 없이 눈이 가장 편안함)
  - **야간전:** 캄캄한 칠흑 같은 극암부(0.05~0.20)를 대낮처럼 집중적으로 끄집어 올리는 4차 곡선
  - **정밀 분리형:** 급감쇠 곡선으로 중간/밝은 톤의 왜곡 없이 어둠 속 대상의 실루엣과 외곽선 분리
  - **e스포츠 트루 블랙:** 0~2% 극저조도는 0에 고정하여 화면이 하얗게 뜨는 '안개 현상(Milky Fog)'을 완벽 차단하고, 3~35% 적 실루엣만 폭발적으로 리프팅
- **세부 튜닝 파라미터:** 틴트(중립/웜/쿨), 눈부심 방지 가드(0~100%), 커스텀 피크(10~40%) 및 대역폭(1~5단계)
- **실시간 2D 감마 커브 & 계조 식별 시각화:** 실시간 피크 리프트 시각화 및 0~10단계 계조 식별 테스트 바 제공

<!-- ----------------------------------------------------------------- -->
<!-- 핵심 기능 5: 글로벌 핫키 -->
<!-- ----------------------------------------------------------------- -->
### ⌨️ 글로벌 핫키

- **Apply:** 단축키로 특정 프로필 즉시 적용
- **Toggle:** 단축키 입력마다 [프로필 적용 ↔ 이전 상태] 토글
- **Cycle:** 지정된 프로필 목록을 순차적으로 순환 적용
- **전체/개별 초기화:** 단일 모니터 또는 연결된 전 모니터 0ms 즉시 리셋
- **Windows 키 지원:** `Win + 키` 조합의 단축키 등록 지원

<!-- ----------------------------------------------------------------- -->
<!-- 핵심 기능 6: 즉시 볼륨 전환 -->
<!-- ----------------------------------------------------------------- -->
### 🔊 즉시 볼륨 전환 (Quick Volume Switch)

- **원터치 볼륨 전환 & 복원:** 글로벌 단축키 한 번으로 목표 볼륨(0~100%)으로 즉시 변경하고, 다시 누르면 깎기 전의 원래 볼륨으로 복원
- **3가지 독립 적용 대상:** 전체 시스템 / 현재 활성화된 창(자동 감지) / 지정한 프로그램
- **Windows 표준 Core Audio API 제어:** 게임 프로세스 변조나 DLL 인젝션 없이 Windows 공식 API로 안전하게 제어
- **상시 표시(Persistent) OSD:** 볼륨이 전환된 상태 동안 화면에 OSD를 계속 띄워두는 알림 옵션 지원

<!-- ----------------------------------------------------------------- -->
<!-- 핵심 기능 7: 동일 모델 다중 모니터 독립 식별 -->
<!-- ----------------------------------------------------------------- -->
### 🖥️ 동일 모델 다중 모니터 독립 식별
- **EDID Serial 기반 정밀 식별:** 프로필 식별 시 가능한 경우 모니터 내부 EDID 시리얼 넘버 기반의 고유 `monitorKey` 사용
- **다중 모니터 설정 뒤바뀜 방지:** 동일 모델 모니터를 2대 이상 연결하여 사용하더라도 각 모니터의 프로필, 토글, 게임 자동 적용 상태가 독립 유지
- **다단계 폴백 매칭:** EDID Serial ➔ Windows PNP Device ID ➔ `DISPLAY` 링크 런타임 보조키 순으로 안전 폴백

<!-- ----------------------------------------------------------------- -->
<!-- 핵심 기능 8: 동영상 프로필 필터 적용 (.bat) 생성 -->
<!-- ----------------------------------------------------------------- -->
### 🎬 동영상 프로필 필터 적용 (.bat) 생성 (Video Filter Generator)

- **모니터 색감 1:1 동영상 동기화:** 선택한 모니터와 프로필의 감마, 대비, 밝기, 채도, 블랙 EQ 수치를 녹화 영상에 그대로 입혀주는 3D LUT(`.cube`) 및 초경량 배치 파일(`.bat`) 자동 생성
- **마우스 드래그 & 드롭 원클릭 적용:** 녹화된 게임 클립을 배치 파일 아이콘에 마우스로 끌어다 놓기만 하면 모니터 색감이 입혀진 영상 자동 생성
- **하드웨어 가속(GPU) 지원:** NVIDIA NVENC, AMD AMF, Intel QSV 고속 인코더 선택 지원

<!-- ----------------------------------------------------------------- -->
<!-- 핵심 기능 9: 프로필 관리 & UI 커스텀 -->
<!-- ----------------------------------------------------------------- -->
### 📋 프로필 관리 및 편의 기능

- 클립보드를 통한 프로필 Import / Export (Hardware ID 식별자 지원)
- 프로필 순서 이동, 정렬, 중복 이름 검증
- 다국어 OSD 알림 팝업 (디스플레이 및 볼륨 전환 알림 위치, 글자 색상, 크기, 표시 시간 개별 커스텀)
- 라이트 / 다크 테마 지원
- 인게임 맵 비교 튜닝용 커스텀 이미지 배너 등록 (주·야간 맵 대조 세팅)

## 📁 데이터 저장 위치

모든 설정, 백업, 로그, 이미지는 로컬 앱데이터 폴더에 안전하게 격리 보관됩니다.

```text
%LOCALAPPDATA%\DisplayProfileManager
├─ config\  (GammaManager.ini 메인 설정)
├─ state\   (시작 시점 원본 화면 백업)
├─ logs\    (프로그램 구동 로그)
├─ backup\  (수동 프로필 백업 INI)
└─ images\  (custom-banner.png 사용자 이미지)
```

> 💡 프로그램 내 **📁 설정 / 로그 폴더 열기** 버튼으로 즉시 접근할 수 있습니다.

## 🛠️ 소스 빌드

### 준비물

- Windows
- Visual Studio 2022 또는 호환되는 Visual Studio 버전
- .NET Framework 4.7.2 Developer Pack

### 빌드 방법

1. 이 저장소를 내려받거나 복제합니다.
2. 솔루션 파일(`Display-Profile-Manager.sln`)을 엽니다.
3. `Debug | Any CPU` 또는 `Release | Any CPU`를 선택합니다.
4. 솔루션을 빌드합니다.

빌드 결과 폴더:

```text
Gamma Manager\Display-Profile-Manager-v1.5.6\
```

실행 파일:

```text
Display-Profile-Manager-v1.5.6.exe
```
