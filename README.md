# Tarkov Gamma Manager v1.5.1

> ## ⚠️ 관리자 권한 실행
>
> **게임을 실행한 상태에서 글로벌 핫키를 사용하려면 프로그램을 관리자 권한으로 실행해야 합니다.**

Escape from Tarkov 할 때 **감마 / 밝기 / 대비 / 채도 같은 화면 설정을 프로필로 묶어서 편하게 바꾸는 Windows용 디스플레이 제어 유틸리티**입니다.

글로벌 핫키(Apply / Toggle / Cycle)로 원하는 프로필을 바로 적용하거나 순환 적용할 수 있으며, 다중 모니터 환경에서도 모니터별 설정과 프로필을 독립적으로 관리할 수 있습니다.

> ⚠️ 이 프로그램은 Battlestate Games 또는 Escape from Tarkov의 공식 프로그램이 아닙니다.

## ✨ v1.5.1 주요 변경사항

v1.5.1 버전은 "프로필 관리 세분화, OSD 편의성 강화, 게임 자동 제거를 통한 구조 단권화 및 디스플레이 제어 안정장치 강화"에 집중했습니다.

### 🚫 게임 자동 적용(Game Auto) 기능 삭제

* 안티치트 프로그램(BattlEye 등)의 오탐 우려를 근본적으로 차단하고, 프로세스 감지 루프 없이 완벽하게 가볍고 명확한 **수동 핫키(Apply / Toggle / Cycle) 제어 방식**으로 전환하기 위해 게임 자동 감지 기능을 전면 삭제했습니다.

### 📋 프로필 관리 기능 대폭 강화 (순서 변경, 정렬, Export & Import)

* **위치 이동 (위 / 아래 / 맨위 / 맨아래):** 프로필 관리 창에서 Shift / Ctrl 다중 선택을 지원하여 원하는 순서대로 프로필을 자유롭게 배치할 수 있습니다.

* **이름순 정렬:** 클릭 한 번으로 프로필 목록을 오름차순(A-Z) 또는 내림차순(Z-A)으로 정렬할 수 있습니다.

* **프로필 공유 (Export & Import):** 프로필 설정을 텍스트 코드로 클립보드에 복사(Export)하거나, 복사된 코드를 붙여넣어(Import) 타 유저와 프로필을 손쉽게 주고받을 수 있습니다.

### 🔁 Cycle (프로필 순환) 핫키 추가

* 프로필 목록에서 `순환` 항목에 체크된 프로필들을 **하나의 글로벌 핫키로 차례대로 순환 적용**할 수 있는 전용 핫키 기능이 추가되었습니다.

### 💬 OSD 팝업 알림 및 커스텀 설정

* 핫키나 프로필 변경 시 화면 상단/좌/우에 알림 팝업을 띄워줍니다.

* **커스텀 옵션:** OSD On/Off, 폰트 색상(초록, 노랑, 하늘색, 흰색, 오렌지, 빨강), 위치(상단 중앙, 좌/우 상단), 폰트 크기(20~48pt), 표시 시간(1.0~3.0초) 설정 지원.

### 📁 앱 데이터 / 로그 폴더 열기 버튼 (📁)

* 프로그램 우측 패널 버튼 클릭 한 번으로 설정, 백업, 로그 파일이 보관되는 `%LOCALAPPDATA%\TarkovGammaManager` 폴더를 바로 열 수 있습니다.

### 🛡️ 디스플레이 제어 안정장치 및 최적화

* **DisplayService 구조 도입:** 디스플레이/하드웨어 제어 및 스레드 병목을 처리하는 전용 서비스 레이어를 도입하여 제어 안정성을 극대화했습니다.

* **DDC/CI 핸들 자동 복구 & 유효성 검증:** 절전 모드 복귀, 해상도 변경, 디스플레이 케이블 재연결 시 `SystemEvents.DisplaySettingsChanged` 이벤트를 감지하여 무효화된 모니터 핸들을 자동으로 재획득합니다.

* **INI 원자적 저장 (Atomic Save):** 임시 파일(`.tmp`) 생성 후 교체하는 원자적 저장 방식을 도입하여 강제 종료 시에도 설정 파일 파손을 방지합니다.

* **윈도우 유니코드 API 매칭 (`EnumDisplayDevicesW`):** 디스플레이 고유명(ACR 등) 및 AMD Saturation / NVIDIA Digital Vibrance 제어 매칭 오류를 완벽히 복구했습니다.

* **로그 자동 정리 (Retention Policy):** 로그 저장 시 7일이 지난 이전 로그 자동 삭제 및 단일 로그 파일 10MB 용량 제한 분할 기능을 적용했습니다.

## 🚀 주요 기능 및 특징

### 🚀 성능 및 최적화 (성능 렉 최소화)

* **슬라이더 렉 완전 해결 (비동기 & 디바운싱):** 밝기/대비 슬라이더 조절 시 백그라운드 처리 및 디바운싱을 통해 UI 프리징(Freezing) 현상을 해결했습니다.

* **INI 100% 메모리 캐싱:** 디스크 입출력 병목을 완전히 제거하여 핫키 동작 시 잔렉이 발생하지 않습니다.

* **WMI 자원 누수 방지:** 노트북 내장 모니터 밝기 조절 시 WMI 연결 객체를 재사용하여 CPU 낭비를 방지합니다.

### 🔄 전체 및 개별 모니터 강제 초기화 (Hard Reset) 핫키

* 화면 설정이 꼬였을 때 언제든지 단 한 번의 핫키 입력으로 프로그램 시작 당시의 원본 디스플레이 상태로 복구할 수 있는 "패닉 버튼" 기능입니다.

* **전체 디스플레이 초기화** 및 **개별 모니터 단독 초기화** 핫키를 각각 설정할 수 있습니다.

### 🎨 테마 이미지 변경 (Killa & Tagilla)

* 우측 데코레이션 이미지를 기본 모니터 이미지 외에 유저들이 선호하는 **Killa & Tagilla 팬아트 이미지**로 변경할 수 있습니다.

## 🔀 프로필 적용 우선순위

수동 핫키 / Toggle / Cycle
↓
Base / 원래 상태


> `Hard Reset`은 별도의 강제 초기화 기능으로, 작동 즉시 현재 상태를 모두 정리하고 시작 당시의 원본 화면 상태로 원복합니다.

## 🎮 상세 기능 안내

### ⌨️ 글로벌 핫키 (Apply / Toggle / Cycle)

* **Apply:** 핫키 입력 즉시 해당 프로필 적용.

* **Toggle:** 첫 번째 입력 시 프로필 적용, 두 번째 입력 시 Toggle 이전 상태로 복구.

* **Cycle:** 지정된 프로필들을 순서대로 순환하며 적용.

### 📋 프로필 목록 관리 (ProfileManagerForm)

* **순서 변경:** 위 / 아래 / 맨위 / 맨아래 이동

* **정렬:** 이름순 오름차순 / 내림차순

* **공유:** 클립보드로 코드 복사 (Export) / 코드 붙여넣기로 프로필 추가 (Import)

### 💬 OSD 팝업 알림 설정 (OSDSettingsForm)

* **표시 위치:** 상단 중앙 / 좌측 상단 / 우측 상단

* **폰트 색상:** 초록 / 노랑 / 하늘색 / 흰색 / 오렌지 / 빨강

* **상세 커스텀:** 폰트 크기(20~48pt), 화면 표시 시간(1.0~3.0초)

## 🔒 안티치트 관련 안내

이 프로그램은 게임 메모리나 프로세스에 전혀 개입하지 않으며, **Windows 디스플레이 API만을 사용하는 모니터 제어 유틸리티**입니다.

소프트웨어 내부에는 다음과 같은 개입 기능이 일절 포함되어 있지 않습니다.

* 게임 프로세스 감지 및 포그라운드 후킹 (v1.5.1에서 완전 제거됨)

* 게임 메모리 읽기 / 쓰기

* DLL Injection / Hooking

* 커널 드라이버 / 패킷 조작 / 화면 캡처

> ⚠️ 안티치트 정책은 개발사가 통제할 수 없으므로 모든 환경에서의 절대적인 탐지 불가 및 안전을 보증하지는 않습니다.

## 📦 설치 및 데이터 저장 위치

별도의 설치 과정이 필요 없는 포터블 실행 방식입니다.

모든 설정, 백업, 로그 파일은 사용자 앱 데이터 폴더에 저장됩니다.

%LOCALAPPDATA%\TarkovGammaManager

├─ config\ (GammaManager.ini 설정 파일)
├─ state\  (StartupBackup 원본 화면 상태 백업)
├─ logs\   (TarkovGammaManager-YYYY-MM-DD.log)
└─ backup\ (수동 프로필 백업)


프로그램 우측 패널의 **📁 설정 / 로그 폴더 열기** 버튼을 누르면 해당 경로가 바로 열립니다.
