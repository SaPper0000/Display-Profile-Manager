# 🖥️ Display Profile Manager v1.5.4

> Windows용 모니터별 디스플레이 프로필, 게임 자동 감지, 즉시 볼륨 전환 및 색상 설정 관리 도구

[![Platform](https://img.shields.io/badge/Platform-Windows-0078D4?logo=windows&logoColor=white)](#)
[![Framework](https://img.shields.io/badge/.NET%20Framework-4.7.2-512BD4?logo=dotnet&logoColor=white)](#)
[![Version](https://img.shields.io/badge/Version-v1.5.4-2EA44F)](#)
[![License](https://img.shields.io/badge/License-CC0%201.0-9CF?logo=creativecommons&logoColor=white)](LICENSE.txt)

Display Profile Manager는 감마, 밝기, 대비, RGB 색상, 채도 같은 화면 설정을 모니터별 프로필로 저장하고 빠르게 적용할 수 있는 Windows용 디스플레이 & 오디오 제어 유틸리티입니다.

게임 실행을 자동으로 감지해 전용 화면 프로필을 켜주거나, 글로벌 핫키(**Apply / Toggle / Cycle**)를 통해 즉각적인 프로필 전환이 가능합니다. 또한, 커스텀 이미지 비교 기능으로 어두운 맵과 밝은 맵을 실시간으로 대조하며 최적의 공용 프로필을 튜닝할 수 있으며, 게임 및 작업 중 단축키 한 번으로 소리를 낮추거나 원하는 볼륨으로 토글하는 **즉시 볼륨 전환(Quick Volume Switch)** 기능을 제공합니다.

> ⚠️ 이 프로그램은 Windows 디스플레이 API, GPU API, 모니터 DDC/CI 및 Windows Core Audio API를 사용합니다. 드라이버 환경, HDR 활성화 여부, 타사 화면 제어 프로그램에 따라 일부 기능 동작이 달라질 수 있습니다.

## 🚀 빠른 시작

1. [Releases](https://github.com/SaPper0000/Display-Profile-Manager/releases)에서 최신 릴리즈 압축 파일을 다운로드합니다.
2. 원하는 위치에 압축을 해제합니다.
3. `Display-Profile-Manager-v1.5.4.exe`를 실행합니다.
4. 상단 모니터 목록에서 제어할 디스플레이를 선택합니다.
5. 슬라이더로 원하는 색상 및 하드웨어 값을 조절한 뒤 프로필을 저장합니다.
6. 필요에 따라 **게임 자동 적용**, **글로벌 핫키**, **즉시 볼륨 전환**을 등록하여 사용합니다.

별도의 설치 과정이 필요 없는 포터블 실행 파일입니다.

## ✨ v1.5.4 릴리즈 변경 사항

### 🆕 새로운 기능 및 주요 개선
- **🔊 즉시 볼륨 전환 (Quick Volume Switch):**
  - 게임이나 작업 중 글로벌 단축키 한 번으로 마스터 볼륨, 현재 활성 창(게임), 또는 지정 프로그램 사운드를 즉각 원하는 볼륨(0~100%)으로 낮추고 다시 누르면 100% 안전 복원합니다.
  - **3가지 적용 모드 지원:** 전체 시스템(마스터/음소거 보존), 현재 활성 창(자동 감지 및 PID+이름 이중 타깃팅), 지정 프로그램(오디오 세션 직접 제어).
  - **Windows 표준 오디오 API 사용:** Windows 표준 Core Audio Session API(`IAudioSessionManager2`)를 사용하여 게임 프로세스 메모리 변조나 DLL 후킹 없이 오디오 세션 레벨에서만 안전하게 동작합니다.
  - **상시 유지(Persistent) OSD:** 볼륨이 전환된 상태임을 계속 인지할 수 있도록 화면에 OSD를 상시 띄워두는 옵션을 지원합니다.
- **🌑 블랙 이퀄라이저 (Black Equalizer) & 3대 알고리즘 모드:**
  - 고가 게이밍 모니터의 하드웨어 Black Equalizer와 동일한 원리로, 일반 감마/밝기 조절과 달리 **밝은 영역(야외, 하늘, 조명)의 눈부심과 화이트아웃 없이 어두운 실내/그늘진 암부(0~35%)의 시인성만 핀셋으로 집중 부스트**합니다.
  - **다양한 환경에 맞춘 3가지 수학 곡선 모드 탑재:**
    1. **FPS 표준 밸런스 (Balanced Toe):** 게이밍 표준의 균일하고 부드러운 3차 곡선 (색 뭉침 없이 눈이 가장 편안함).
    2. **야간전 (Night Mode / Deep Shadow):** 칠흑 같은 어둠(0.05~0.20)을 집중적으로 끌어올리는 4차 극암부 특화 (캄캄한 실내/야간 환경).
    3. **정밀 분리형 (Precision Spline):** 급감쇠 곡선으로 중간/밝은 톤의 왜곡 없이 어둠 속 대상의 실루엣과 외곽선 분리.
  - 상단 제어판의 **`[블랙 EQ]`** 버튼을 클릭하여 열리는 전용 창에서 모드와 슬라이더(0~100%)를 조절하면 **창 뒤의 게임 화면이나 프리뷰 이미지에 실시간으로 즉시 반영**되어 최적값을 손쉽게 찾을 수 있으며, 원터치 프리셋(`0% 끄기`, `25% 약`, `50% 중`, `75% 강`) 및 프로필 저장을 완벽 지원합니다.
- **🎨 확장 대비 (최대 10.00) 정식 지원:**
  - 기존 3.00 한계 클램핑을 해제하여 확장 대비 모드 사용 시 최대 10.00까지 고대비 감마 램프를 정상 생성 및 적용합니다.

###  버그 수정
- **v1.5.4 프로필 가져오기 식별자 보존:** `DPM154|` 공유 코드 임포트 시 모니터 고유 식별자(`hardwareId`, `monitorKey`)가 INI에 온전히 기록되도록 보정.
- **활성 창 볼륨 복원 안정화:** 다국어 환경에서 프로세스 이름 식별자 불일치로 인한 복원 실패 가능성을 제거.

### ⚡ 오류 방지 및 성능 최적화
- **창 전환(Alt+Tab) CPU 병목 제거:** 게임 자동 전환 감시 시 전체 시스템 프로세스 풀 스캔 대신 기억된 PID 기반 O(1) 초고속 생존 검사로 CPU 점유 스파이크 제거.
- **OSD 크로스 스레드 예외 차단:** `HideOSD` 호출 시 UI 스레드 마샬링(`InvokeRequired` / `BeginInvoke`)을 적용해 스레드 충돌 및 프리징 원천 방지.
- **Core Audio COM 자원 안전 해제:** `SafeRelease` 패턴을 통한 메모리 누수 방지 및 오디오 장치 변경/재연결 시 안전 복구 보장.

### 🌑 블랙 이퀄라이저 (Black Equalizer / Black EQ)
- **암부 전용 비선형 부스트:** 일반 감마 조절과 달리 하늘·조명 등 밝은 영역(80~100%)의 눈부심(화이트아웃) 없이, 어두운 그늘과 실내 암부(0~35%)의 시인성만 핀셋처럼 집중 향상
- **3대 알고리즘 모드 지원:**
  - **FPS 표준 밸런스:** 게이밍 표준의 균일하고 부드러운 3차 토우 곡선 (색 뭉침 없이 눈이 가장 편안함)
  - **야간전:** 캄캄한 칠흑 같은 극암부(0.05~0.20)를 대낮처럼 집중적으로 끄집어 올리는 4차 곡선
  - **정밀 분리형:** 급감쇠 곡선으로 중간/밝은 톤의 왜곡 없이 어둠 속 대상의 실루엣과 외곽선 분리
- **실시간 프리뷰 창 & 원터치 제어:**
  - 상단 제어판의 `[블랙 EQ]` 버튼을 통해 전용 창에서 슬라이더를 조절하면 화면에 실시간 즉각 반영
  - 원터치 프리셋(`0% 끄기`, `25% 약`, `50% 중`, `75% 강`) 및 프로필 자동 저장/복원 완벽 지원

### 🔊 즉시 볼륨 전환 (Quick Volume Switch)

- **원터치 볼륨 전환 & 복원:** 글로벌 단축키 한 번으로 목표 볼륨(0~100%)으로 즉시 변경하고, 다시 누르면 깎기 전의 원래 볼륨으로 복원
- **3가지 독립 적용 대상:**
  - **전체 시스템:** 마스터 볼륨 및 음소거 상태 토글
  - **현재 활성화된 창 (자동 감지):** 키 입력 순간 포커스된 게임/앱 프로세스만 즉시 조절 (멀티프로세스 오디오 렌더러 완벽 대응)
  - **지정한 프로그램:** 시스템 내 실행 중인 오디오 세션 중 원하는 프로그램만 선택 제어
- **Windows 표준 API 제어:** 게임 프로세스 변조나 DLL 인젝션 없이 Windows 공식 Core Audio Session API를 통해 운영체제 레벨에서 안전하게 볼륨 제어
- **상시 표시(Persistent) OSD:** 볼륨이 전환된 상태 동안 화면에 OSD를 계속 띄워두는 알림 옵션 지원

### 🖥️ 동일 모델 다중 모니터 독립 식별
- **EDID Serial 기반 정밀 식별:** 프로필 식별 시 가능한 경우 모니터 내부 EDID 시리얼 넘버 기반의 고유 `monitorKey`를 사용합니다.
- **다중 모니터 설정 뒤바뀜 방지:** 동일 모델(동일 제조사/동일 제품명) 모니터를 2대 이상 연결하여 사용하더라도 각 모니터의 프로필, 토글, 게임 자동 적용 상태가 뒤바뀌지 않고 독립적으로 유지됩니다.
- **다단계 폴백 매칭:** EDID Serial을 제공하지 않는 모니터는 Windows PNP Device ID를 사용하고, 현재 세션에서 동일 값까지 겹치면 `DISPLAY` 링크를 런타임 보조키로 사용하여 연결 안정성을 보장합니다.

## 📁 데이터 저장 위치

모든 설정, 백업, 로그, 이미지는 로컬 앱데이터 폴더에 안전하게 격리 보관됩니다.

```text
%LOCALAPPDATA%\DisplayProfileManager
├─ config\  (GammaManager.ini 메인 설정)
├─ state\   (시작 시점 원본 화면 백업)
├─ logs\    (프로그램 구동 로그)
├─ backup\  (수동 프로필 백업 INI)
└─ images\  (custom-banner.png 사용자 이미지)
```

> 💡 프로그램 내 **📁 설정 / 로그 폴더 열기** 버튼으로 즉시 접근할 수 있습니다.
