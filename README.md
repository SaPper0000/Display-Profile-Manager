# Tarkov Gamma Manager v1.4.0

Windows display profile manager for Escape from Tarkov.

## Source

- 🇰🇷 Korean: `Korean/`
- 🇺🇸 English: `English/`

Both source trees are kept separate so the Korean and English builds cannot overwrite each other.

## Build

Open the solution inside the language folder with Visual Studio 2022 and build the `Release` configuration.

Both builds include the same core functionality and require administrator privileges at startup.
