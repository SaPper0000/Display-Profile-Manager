# 🖥️ Display Profile Manager v1.5.8

> Windows용 모니터별 디스플레이 프로필, 게임 자동 감지, 볼륨 전환, 화면 필터 스크린샷, 동영상 프로필 필터 및 색상 설정 관리 도구

[![Platform](https://img.shields.io/badge/Platform-Windows-0078D4?logo=windows&logoColor=white)](#)
[![Framework](https://img.shields.io/badge/.NET%20Framework-4.8-512BD4?logo=dotnet&logoColor=white)](#)
[![Version](https://img.shields.io/badge/Version-v1.5.8-2EA44F)](#)
[![License](https://img.shields.io/badge/License-CC0%201.0-9CF?logo=creativecommons&logoColor=white)](LICENSE.txt)

Display Profile Manager는 감마, 밝기, 대비, RGB 색상, 채도, 하드웨어 DDC/CI 등 화면 설정을 모니터별 프로필로 저장하고 적용할 수 있는 Windows용 디스플레이 및 오디오 제어 유틸리티입니다.

실행 중인 게임을 감지해 지정된 화면 프로필을 자동 적용하거나, 글로벌 핫키(**Apply / Toggle / Cycle**)로 프로필을 전환할 수 있습니다. 또한 사용자 이미지를 띄워 색감을 비교하는 **커스텀 이미지 프리뷰**, 단축키로 볼륨을 낮추고 복원하는 **즉시 볼륨 전환(Quick Volume Switch)**, 소프트웨어 필터가 반영된 화면을 저장하는 **화면 필터 스크린샷(Filtered Screenshot)**, 녹화 영상 및 이미지에 프로필 색감을 입히는 **동영상 프로필 필터 적용(.bat)** 기능을 제공합니다.

> ⚠️ 이 프로그램은 Windows 디스플레이 API, GPU 드라이버 API, 모니터 DDC/CI 및 Windows Core Audio API를 사용합니다. 그래픽 드라이버 환경, HDR 활성화 여부, 타사 화면 제어 프로그램에 따라 일부 기능 동작이 달라질 수 있습니다.

## 🚀 빠른 시작

1. [Releases](https://github.com/SaPper0000/Display-Profile-Manager/releases)에서 최신 릴리즈 압축 파일을 다운로드합니다.
2. 원하는 폴더에 압축을 해제합니다.
3. `Display-Profile-Manager-v1.5.8.exe`를 실행합니다.
4. 상단 모니터 목록에서 제어할 디스플레이를 선택합니다.
5. 슬라이더로 색상 및 하드웨어 값을 조절한 뒤 프로필을 저장합니다.
6. 필요에 따라 **게임 자동 적용**, **글로벌 핫키**, **즉시 볼륨 전환**, **화면 필터 스크린샷**, **동영상 프로필 필터**를 설정해 사용합니다.

별도의 설치 과정이 필요 없는 포터블 실행 파일입니다.

- **⌨️ 단축키 다중 조합키(Ctrl / Alt / Shift / Win) 자유 지정 지원:**

  - 다른 프로그램이나 게임이 이미 선점한 단축키인 경우 충돌 경고 안내

- **⏱️ 장시간 실행 시 단축키 딜레이 오류 수정:**
  - PC를 수십 일 이상 재부팅 없이 장시간 켜두었을 때 핫키 쿨다운 계산이 꼬이던 타이머 오버플로우 문제 해결
- **📦 v1.5.8 프로필 클립보드 공유:**
  - 프로필 공유 포맷(`TGM-Profile|v1.5.8|...`) 갱신 및 이전 버전(v1.5.7 이하) 하위 호환 유지

### ⚡ 안정성 및 버그 수정
- **화면 변경 후 프로그램 종료 시 채도 복원 정상화:** 해상도/주사율 변경이나 모니터 재연결 후에도 앱 시작 시점의 원래 채도(Digital Vibrance)가 정상 복원되도록 개선
- **노트북 내장 패널 밝기 조회 비동기화:** 내장 화면 밝기 조회를 백그라운드로 전환하여 화면 전환 시 순간적인 UI 멈춤(프리징) 현상 해결
- **게임 선택 창 안티치트 안전성 극대화:** 프로세스 목록 조회 시 안티치트(BattlEye/EAC 등)가 허용하는 최소 권한만 사용하여 권한 거부 오류 및 충돌 원천 차단
- **동영상 필터 배치 파일(`.bat`) 특수문자 오류 수정:** 파일명에 느낌표(`!`)나 특수문자가 포함된 미디어 드래그 앤 드롭 시 변환 실패하던 CMD 파싱 문제 해결 및 3D LUT 변환 속도 대폭 개선
- **4K 스크린샷 멀티코어 병렬 처리:** 고해상도 화면 캡처 시 멀티스레드 병렬 연산을 적용하여 순간 지연(스터터링) 개선
- **화면 초기화(하드 리셋) 보정:** 블랙 EQ 커스텀 대역폭 리셋 누락 수정 및 프로필 전환 시 비동기 명령 경합 안정화

### 🎨 디스플레이 색상 및 하드웨어 제어

| 제어 항목 | 설명 | 제어 방식 |
|---|---|---|

| 외장 모니터 밝기/대비 | 모니터 하드웨어 밝기 및 대비 조절 | DDC/CI (`dxva2.dll`) |

### 🌑 블랙 이퀄라이저 (Black Equalizer / Black EQ)
- **암부 비선형 보정:** 어두운 영역(0~35%) 위주로 밝기를 끌어올리고 밝은 영역의 왜곡을 억제
- **커브 모드 지원:**
  - **FPS 표준 밸런스:** 암부 전반을 완만하게 보정
  - **야간전:** 저조도(5~20%) 구간을 집중 보정
  - **정밀 분리형:** 중간 톤 변화를 줄이고 암부 경계 구분을 보정
  - **e스포츠 트루 블랙:** 0~2% 극암부는 유지하고 3~35% 구간을 보정
  - **커스텀 대역폭:** 피크 위치(10~40%)와 대역폭(1~5단계)을 직접 설정
- **눈부심 방지 가드:** 밝은 영역(하이라이트) 톤 압축 강도(0~100%) 조절
- **커브 그래프 및 계조 테스트 바:** 설정 창 내 커브 미리보기 및 전체화면 계조 확인 뷰어 제공

<!-- ----------------------------------------------------------------- -->
<!-- 핵심 기능 5: 글로벌 핫키 -->
<!-- ----------------------------------------------------------------- -->
### ⌨️ 글로벌 핫키

- **Apply:** 단축키로 지정 프로필 적용
- **Toggle:** 단축키 입력 시 [프로필 적용 ↔ 이전 상태] 전환
- **Cycle:** 순환 목록에 포함된 프로필을 순서대로 전환
- **전체/개별 초기화:** 단일 모니터 또는 전체 모니터 설정 초기화
- **조합키 지원:** `Ctrl`, `Alt`, `Shift`, `Win` 다중 조합 단축키 등록 지원

<!-- ----------------------------------------------------------------- -->
<!-- 핵심 기능 6: 즉시 볼륨 전환 -->
<!-- ----------------------------------------------------------------- -->
### 🔊 즉시 볼륨 전환 (Quick Volume Switch)

- **볼륨 토글:** 단축키로 지정 볼륨(0~100%)으로 변경하고, 재입력 시 원래 볼륨으로 복원
- **적용 대상 선택:** 시스템 마스터 볼륨 / 현재 활성 창 프로세스 / 지정 프로세스
- **OSD 알림:** 볼륨 전환 시 화면 알림 표시 (상시 유지 옵션 포함)

<!-- ----------------------------------------------------------------- -->
<!-- 핵심 기능 7: 동일 모델 다중 모니터 독립 식별 -->
<!-- ----------------------------------------------------------------- -->
### 🖥️ 동일 모델 다중 모니터 독립 식별
- **EDID Serial 기반 식별:** 모니터 레지스트리의 EDID 시리얼 번호와 PNP ID를 조합한 `monitorKey` 사용
- **다중 모니터 프로필 분리:** 동일 모델 모니터를 여러 대 연결한 환경에서도 모니터별 프로필, 토글, 게임 자동 적용 상태를 개별 유지
- **폴백 매칭:** EDID Serial ➔ Windows PNP Device ID ➔ `DISPLAY` 링크 순서로 식별

<!-- ----------------------------------------------------------------- -->
<!-- 핵심 기능 8: 동영상 프로필 필터 적용 (.bat) 생성 -->
<!-- ----------------------------------------------------------------- -->
### 🎬 동영상 프로필 필터 (.bat) 생성

- **미디어 색감 변환:** 선택한 프로필의 감마, 대비, 밝기, 채도, 블랙 EQ 수치를 반영한 3D LUT(`.cube`)와 배치 파일(`.bat`) 생성
- **드래그 앤 드롭 처리:** 동영상(`.mp4`, `.mkv`, `.mov` 등), 이미지(`.png`, `.jpg` 등), 움짤(`.gif`, `.webp`) 파일을 배치 파일에 끌어다 놓아 변환
- **하드웨어 인코더 지원:** NVIDIA NVENC, AMD AMF, Intel QSV 및 CPU(`libx264`) 선택 지원

<!-- ----------------------------------------------------------------- -->
<!-- 핵심 기능 9: 프로필 관리 & UI 커스텀 -->
<!-- ----------------------------------------------------------------- -->
### 📋 프로필 관리 및 편의 기능

- 클립보드를 통한 프로필 공유 문자열 복사 및 붙여넣기
- 프로필 순서 이동, 이름 변경, 정렬, INI 백업 및 복원
- 한국어 / 영어 인터페이스 전환 및 라이트 / 다크 테마 지원
- OSD 알림 위치, 글자 색상, 크기, 표시 시간 설정
- 프리뷰 영역 사용자 이미지 등록 지원

## 📁 데이터 저장 위치

설정, 상태 백업, 로그, 사용자 이미지는 로컬 앱데이터 경로에 저장됩니다.

```text
%LOCALAPPDATA%\DisplayProfileManager
├─ config\  (GammaManager.ini 메인 설정)
├─ state\   (시작 시점 원본 화면 백업)
├─ logs\    (프로그램 구동 로그)
├─ luts\    (동영상 필터용 3D LUT .cube 파일)
├─ bin\     (동영상 필터용 ffmpeg.exe)
└─ images\  (custom-banner.png 사용자 이미지)
```

> 💡 메인 화면의 **📁 설정 / 로그 폴더** 버튼으로 해당 경로를 바로 열 수 있습니다.

## 🛠️ 소스 빌드

### 준비물

- Windows
- Visual Studio 2022 또는 호환되는 Visual Studio 버전
- .NET Framework 4.8 Developer Pack

### 빌드 방법

1. 이 저장소를 내려받거나 복제합니다.
2. 솔루션 파일(`Display-Profile-Manager.sln`)을 엽니다.
3. `Debug | Any CPU` 또는 `Release | Any CPU`를 선택합니다.
4. 솔루션을 빌드합니다.

빌드 결과 폴더:

```text
Gamma Manager\Display-Profile-Manager-v1.5.8\
```

실행 파일:

```text
Display-Profile-Manager-v1.5.8.exe
```
