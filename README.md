# Tarkov Gamma Manager

**Escape from Tarkov 플레이 환경을 위한 Windows 디스플레이 프로필 관리 프로그램**

모니터 감마, 밝기, 대비 등의 설정을 프로필로 저장하고, 게임 자동 실행이나 단축키를 이용해 빠르게 전환할 수 있도록 만든 프로그램입니다.

> ⚠️ 이 프로그램은 Battlestate Games 또는 Escape from Tarkov의 공식 프로그램이 아닙니다.

---

## ✨ 주요 기능

### 🎮 게임 자동 프로필

지정한 게임이 실행되면 미리 설정한 프로필을 자동으로 적용합니다.

예:

```text
Tarkov 실행
    ↓
A 프로필 자동 적용
```

게임 종료 시에는 프로그램에 저장된 이전 디스플레이 상태를 기준으로 복구할 수 있습니다.

---

### 🎛️ 디스플레이 프로필

모니터별 디스플레이 설정을 프로필로 저장하고 필요할 때 불러올 수 있습니다.

여러 대의 모니터를 사용하는 환경에서도 각 모니터의 설정을 관리할 수 있도록 구성되어 있습니다.

프로그램 실행 시 감지된 모니터의 기본 설정을 저장하여 이후 프로필 관리에 사용할 수 있습니다.

---

### ⌨️ 핫키

각 프로필에 원하는 단축키를 지정할 수 있습니다.

#### 적용 (Apply)

단축키를 누르면 지정된 프로필을 적용합니다.

#### 토글 (Toggle)

단축키를 누르면 해당 프로필로 전환하고, 같은 단축키를 다시 누르면 전환 직전에 사용하던 프로필로 돌아갑니다.

예:

```text
게임 자동
    ↓
A 프로필 적용

F11
    ↓
B 프로필 적용

F11
    ↓
A 프로필 복귀
```

따라서 게임 자동으로 A 프로필을 사용하면서 필요할 때만 B 프로필을 잠시 사용하는 방식으로 활용할 수 있습니다.

---

### 💾 프로필 백업 / 복원

저장된 프로필과 프로그램 설정을 백업 파일로 저장할 수 있습니다.

새 버전으로 업데이트하기 전에 백업해 두면 기존 설정을 보관할 수 있으며, 문제가 발생했을 때 복원할 수 있습니다.

> 업데이트 전에는 `백업` 기능을 사용하는 것을 권장합니다.

---

### 🖥️ 모니터 조절

모니터 밝기 및 대비 조절 기능을 제공합니다.

`모니터 조절 사용`은 기본적으로 꺼져 있습니다.

기능이 꺼져 있을 때는 관련 조절 항목도 비활성화되어 실수로 값을 변경하지 않도록 구성되어 있습니다.

### 🔘 편의 기능 토글

자주 사용하는 기능은 체크박스 및 토글 방식으로 간단하게 켜고 끌 수 있도록 구성되어 있습니다.

- 모니터 조절 사용 여부
- RGB 관련 기능
- 기타 프로그램 편의 기능

### 📌 창 맨 위 고정

프로그램 창을 항상 다른 창보다 위에 표시할지 선택할 수 있습니다.

`창 맨위 고정`은 기본적으로 켜져 있으며, 체크를 해제하면 일반적인 Windows 창처럼 다른 창 뒤로 이동할 수 있습니다.

설정 상태는 저장되므로 다음 실행 시에도 마지막으로 선택한 상태를 유지합니다.

---

### 🌐 한국어 / 영어 지원

프로그램 UI는 다음 두 가지 언어를 제공합니다.

- 한국어
- English

## 📦 설치 및 실행

별도의 설치 프로그램 없이 사용할 수 있는 포터블 방식으로 배포합니다.

기본 실행은 일반 사용자 권한으로 동작하며, 프로그램이 관리자 권한을 강제로 요구하지 않습니다. 필요한 경우 Windows의 `관리자 권한으로 실행`을 사용해 직접 관리자 권한으로 실행할 수 있습니다.

1. GitHub의 **Releases**에서 원하는 언어의 ZIP 파일을 다운로드합니다.
2. ZIP 파일의 압축을 해제합니다.
3. `Tarkov Gamma Manager v1.4.exe`를 실행합니다.

처음 사용하는 경우 프로그램의 프로필과 모니터 설정을 먼저 확인한 후 사용하는 것을 권장합니다.

---

## 💾 설정 백업 권장

프로그램을 업데이트하기 전에는 다음 순서를 권장합니다.

```text
현재 버전 실행
    ↓
백업
    ↓
새 버전 업데이트
    ↓
문제 발생 시 복원
```

백업 파일은 향후 버전 업데이트에 대비한 개인 설정 보관 용도로 사용할 수 있습니다.

---

## 🛠️ 직접 빌드하기

이 프로젝트는 Visual Studio에서 솔루션을 열어 직접 빌드할 수 있습니다.

```text
Tarkov-Gamma-Manager-v1.4.sln
```

권장 빌드 구성:

```text
Configuration: Release
Platform:     Any CPU
```

일반 사용자는 GitHub Releases에서 제공되는 배포 파일을 사용하는 것을 권장합니다.

## 🔒 안티치트 관련

이 프로그램은 **게임 내부 기능을 조작하기 위한 프로그램이 아닙니다.**

프로그램의 주요 목적은 Windows 환경에서 모니터 및 디스플레이 설정을 관리하는 것입니다.

프로젝트에는 다음과 같은 게임 조작 기능을 의도적으로 포함하지 않습니다.

- 게임 메모리 읽기 / 쓰기
- DLL Injection
- 게임 DLL Hooking
- 커널 드라이버
- 게임 파일 수정
- 패킷 조작
- 게임 메모리 스캔
- 게임 내부 오버레이

게임 자동 기능은 지정된 게임 프로세스의 실행 여부를 확인한 뒤 설정된 프로필을 적용하는 용도로 사용합니다.

### ⚠️ 중요

이 내용은 프로그램의 기술적인 동작 범위를 설명하기 위한 것입니다.

Escape from Tarkov 또는 BattlEye의 탐지 방식과 정책은 개발자가 통제할 수 없으며 향후 변경될 수 있습니다.

따라서 **이 프로그램이 게임의 안티치트에 의해 항상 안전하게 허용된다고 보증하지 않습니다.**

사용자는 게임 및 안티치트 정책을 확인한 후 프로그램을 사용하는 것이 좋습니다.

## ⚠️ 주의사항

- 이 프로그램은 Battlestate Games의 공식 프로그램이 아닙니다.

- 프로그램 사용으로 인해 발생할 수 있는 게임 이용 제한, 설정 손실 또는 기타 문제에 대해서는 개발자가 책임지지 않습니다.
