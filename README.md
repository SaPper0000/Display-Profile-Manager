# Tarkov Gamma Manager v1.4.3

Escape from Tarkov 플레이 환경을 위한 **Windows 모니터 감마 및 디스플레이 프로필 관리 프로그램**입니다.

감마·밝기·대비 등의 디스플레이 설정을 프로필로 저장하고, 게임 자동 적용이나 단축키를 이용해 빠르게 전환할 수 있습니다.

> ⚠️ 이 프로그램은 Battlestate Games 또는 Escape from Tarkov의 공식 프로그램이 아닙니다.
>

## ✨ v1.4.3 주요 변경사항

이번 버전에서는 **GPU별 색상 조절 기능**이 추가되었습니다.

### 🟥 AMD - 채도 (Saturation)

AMD 그래픽 환경에서 지원되는 경우 모니터별 **채도(Saturation)** 를 조절할 수 있습니다.

### 🟩 NVIDIA - 디지털 바이브런스 (Digital Vibrance)

NVIDIA 그래픽 환경에서는 **디지털 바이브런스(Digital Vibrance)** 를 조절할 수 있습니다.

### ⌨️ 숫자 직접 입력

채도 / 디지털 바이브런스 조절바 오른쪽의 숫자 입력칸에 원하는 값을 직접 입력할 수 있습니다.

- 숫자 값을 직접 입력
- `Enter` 입력으로 즉시 적용
- 입력칸에서 포커스를 벗어나도 값 적용
- 슬라이더와 숫자 입력값이 서로 연동

## 🎮 주요 기능

### 게임 자동 프로필

지정한 게임이 실행되면 미리 설정한 프로필을 자동으로 적용합니다.

예:

```text
Tarkov 실행
    ↓
Tarkov 프로필 자동 적용
```

### 🖥️ 모니터별 디스플레이 설정

여러 대의 모니터를 사용하는 환경에서도 모니터별로 설정을 관리할 수 있습니다.

프로필에 다음과 같은 디스플레이 설정을 저장할 수 있습니다.

- 감마
- 밝기
- 대비
- AMD 채도
- NVIDIA 디지털 바이브런스

### ⌨️ 프로필 핫키

각 프로필에 글로벌 단축키를 지정할 수 있습니다.

**Apply** 방식은 단축키를 누르면 지정된 프로필을 적용합니다.

**Toggle** 방식은 단축키를 누르면 지정된 프로필로 전환하고, 다시 누르면 이전 프로필로 돌아갑니다.

### 💾 프로필 백업 / 복원

저장된 프로필과 프로그램 설정을 백업하고 복원할 수 있습니다.

새 버전으로 업데이트하기 전에 백업하는 것을 권장합니다.

## 📦 설치 및 실행

별도의 설치 프로그램 없이 사용할 수 있는 **포터블 방식**으로 배포합니다.

1. GitHub Releases에서 원하는 버전의 ZIP 파일을 다운로드합니다.
2. ZIP 파일의 압축을 해제합니다.
3. `Tarkov Gamma Manager v1.4.exe`를 실행합니다.
4. 처음 사용하는 경우 모니터와 프로필 설정을 확인한 후 사용합니다.

필요한 경우 실행 파일을 **관리자 권한으로 실행**할 수 있습니다.

## ⚙️ 설정 사용 예시

Tarkov를 실행할 때 화면을 더 밝고 선명하게 사용하고 싶다면:

```text
1. Tarkov용 프로필 생성
2. 감마 / 밝기 / 대비 조절
3. NVIDIA라면 디지털 바이브런스 조절
   AMD라면 채도 조절
4. 프로필 저장
5. 게임 자동 설정에서 Tarkov 실행 파일 지정
6. Tarkov 실행 → 해당 프로필 자동 적용
```

## 🛠️ 직접 빌드하기

개발 또는 소스 수정이 필요한 경우 Visual Studio에서 솔루션을 열어 직접 빌드할 수 있습니다.

- 대상 프레임워크: **.NET Framework 4.7.2**
- 구성: **Release**
- 플랫폼: **Any CPU**
- `Prefer32Bit=false`

Visual Studio에서 솔루션을 연 뒤 **Rebuild Solution(솔루션 다시 빌드)** 을 사용하는 것을 권장합니다.

일반 사용자는 직접 빌드하지 않고 GitHub Releases에서 제공되는 배포 파일을 사용하는 것을 권장합니다.

## 🔒 안티치트 관련 안내

이 프로그램은 게임 내부 기능을 조작하는 프로그램이 아닙니다.

주요 목적은 Windows 환경에서 모니터 및 디스플레이 설정을 관리하는 것입니다.

다음과 같은 기능은 포함하지 않습니다.

- 게임 메모리 읽기 / 쓰기
- DLL Injection
- 게임 DLL Hooking
- 커널 드라이버
- 게임 파일 수정
- 패킷 조작
- 게임 메모리 스캔
- 게임 내부 오버레이

게임 자동 기능은 지정된 게임 프로세스의 실행 여부를 확인하고 설정된 디스플레이 프로필을 적용하는 용도로 사용합니다.

> ⚠️ 다만 Escape from Tarkov 또는 BattlEye의 탐지 방식과 정책은 개발자가 통제할 수 없으며 향후 변경될 수 있습니다. 따라서 안티치트에 의해 항상 안전하게 허용된다고 보증하지 않습니다.

## ⚠️ 주의사항

- AMD 채도 및 NVIDIA 디지털 바이브런스는 사용 중인 GPU/드라이버 환경에 따라 지원 여부가 다를 수 있습니다.
- 일부 모니터에서는 밝기·대비 등의 값을 읽거나 변경하는 데 제한이 있을 수 있습니다.
- 모니터의 DDC/CI 지원 여부에 따라 일부 기능이 정상적으로 동작하지 않을 수 있습니다.
- 업데이트 전에는 기존 프로필을 백업하는 것을 권장합니다.
- 이 프로그램은 Battlestate Games의 공식 프로그램이 아닙니다.
- 프로그램 사용으로 인해 발생할 수 있는 게임 이용 제한, 설정 손실 또는 기타 문제에 대해서는 개발자가 책임지지 않습니다.
