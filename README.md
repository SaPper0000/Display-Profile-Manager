# 🖥️ Display Profile Manager v1.5.6


<img width="1082" height="752" alt="image" src="https://github.com/user-attachments/assets/df4029b0-836f-40c4-8d7e-39e8e9aa505b" />


> Windows용 모니터별 디스플레이 프로필, 게임 자동 감지, 즉시 볼륨 전환, 화면 필터 스크린샷, 동영상 프로필 필터 및 색상 설정 관리 도구

[![Platform](https://img.shields.io/badge/Platform-Windows-0078D4?logo=windows&logoColor=white)](#)
[![Framework](https://img.shields.io/badge/.NET%20Framework-4.7.2-512BD4?logo=dotnet&logoColor=white)](#)
[![Version](https://img.shields.io/badge/Version-v1.5.6-2EA44F)](#)
[![License](https://img.shields.io/badge/License-CC0%201.0-9CF?logo=creativecommons&logoColor=white)](LICENSE.txt)

Display Profile Manager는 감마, 밝기, 대비, RGB 색상, 채도, 하드웨어 DDC/CI 같은 화면 설정을 모니터별 프로필로 저장하고 빠르게 적용할 수 있는 Windows용 디스플레이 & 오디오 통합 제어 유틸리티입니다.

게임 실행을 자동으로 감지해 전용 화면 프로필을 켜주거나, 글로벌 핫키(**Apply / Toggle / Cycle**)를 통해 즉각적인 프로필 전환이 가능합니다. 또한, 어두운 맵과 밝은 맵을 실시간으로 대조하며 최적의 공용 프로필을 튜닝하는 **커스텀 이미지 비교 기능**, 게임 및 작업 중 단축키 한 번으로 소리를 낮추거나 원하는 볼륨으로 토글하는 **즉시 볼륨 전환(Quick Volume Switch)**, 모니터에서 튜닝한 색감을 그대로 캡처하는 **화면 필터 스크린샷(Filtered Screenshot)**, 그리고 녹화 영상에 화면 튜닝 색감을 그대로 적용하는 **동영상 프로필 필터 적용** 기능을 제공합니다.

> ⚠️ 이 프로그램은 Windows 디스플레이 API, GPU API, 모니터 DDC/CI 및 Windows Core Audio API를 사용합니다. 드라이버 환경, HDR 활성화 여부, 타사 화면 제어 프로그램에 따라 일부 기능 동작이 달라질 수 있습니다.

## 🚀 빠른 시작

1. [Releases](https://github.com/SaPper0000/Display-Profile-Manager/releases)에서 최신 릴리즈 압축 파일을 다운로드합니다.
2. 원하는 위치에 압축을 해제합니다.
3. `Display-Profile-Manager-v1.5.6.exe`를 실행합니다.
4. 상단 모니터 목록에서 제어할 디스플레이를 선택합니다.
5. 슬라이더로 원하는 색상 및 하드웨어 값을 조절한 뒤 프로필을 저장합니다.
6. 필요에 따라 **게임 자동 적용**, **글로벌 핫키**, **즉시 볼륨 전환**, **화면 필터 스크린샷**, **동영상 프로필 필터**를 등록하여 사용합니다.

별도의 설치 과정이 필요 없는 포터블 실행 파일입니다.

## ✨ v1.5.6 릴리즈 변경 사항

### 🆕 새로운 기능 및 개선
- **📸 화면 필터 스크린샷 (Filtered Screenshot):**
  - 모니터에 적용된 감마, 대비, 밝기, 채도, 블랙 EQ, 하이라이트 가드 설정을 캡처 이미지에 반영
  - 글로벌 단축키 지정 및 해제 지원
  - 스크린샷 / 볼륨 / 디스플레이 프로필 단축키 간 상호 중복 검사 및 경고 팝업 안내 지원
  - 클립보드 복사 및 파일 저장(PNG / JPG) 지원
  - 캡처 시 효과음 재생 및 화면 OSD 알림 옵션 제공
  - 메인 UI에 [📸 필터 스크린샷 설정] 버튼 및 단축키 상태 표시 추가

- **🌑 블랙 이퀄라이저 (Black EQ) 세부 설정 추가:**
  - 눈부심 방지 가드 (0~100%) 조절 지원
  - 커스텀 피크 중심 (10% ~ 40%) 및 대역폭 (1~5단계) 조절 지원

- **📦 v1.5.6 프로필 공유 지원:**
  - 클립보드 프로필 공유(`TGM-Profile|v1.5.6|...`) 시 블랙 EQ 세부 설정(가드, 커스텀 피크/대역폭) 포함

### ⚡ 내부 구조 및 안정성 개선
- **프로필 데이터 처리 일원화 (`ProfileData`):** 디스플레이 파라미터의 INI 저장/로드 로직을 일원화하여 코드 중복 제거 및 수치 정규화 개선
- **게임 자동 감지 전환 안정화:** 창 전환(`Alt + Tab`) 시 스레드 경합을 방지하여 프로필 전환 안정성 향상
- **DDC/CI 통신 안정화:** 모니터 하드웨어 통신 자원 관리 개선

### 🌑 블랙 이퀄라이저 (Black Equalizer / Black EQ)
- **암부 비선형 보정:** 밝은 영역 왜곡을 줄이고 어두운 암부(0~35%) 영역의 밝기를 보정
- **4가지 커브 모드 지원:**
  - **FPS 표준 밸런스:** 완만한 3차 곡선 형태로 균일하게 암부 보정
  - **야간전:** 극저조도(0.05~0.20) 영역을 집중 보정
  - **정밀 분리형:** 중간 톤 왜곡 없이 어두운 대상의 외곽선 구분 지원
  - **e스포츠 트루 블랙:** 0~2% 극저조도는 유지하여 들뜸을 줄이고 3~35% 암부 보정
- **세부 조절:** 눈부심 방지 가드(0~100%), 피크 위치(10~40%) 및 대역폭(1~5단계)
- **감마 커브 그래프 및 계조 테스트 바:** 감마 커브 변화와 0~10단계 계조 식별 바 제공

### ⌨️ 글로벌 핫키

- **Apply:** 단축키로 특정 프로필 즉시 적용

### 🔊 즉시 볼륨 전환 (Quick Volume Switch)

- **볼륨 토글:** 글로벌 단축키로 설정한 볼륨(0~100%)으로 즉시 전환하고, 다시 누르면 이전 볼륨으로 복원
- **적용 대상 선택:** 전체 시스템 마스터 볼륨 / 현재 활성화된 창(자동 감지) / 지정 프로그램
- **OSD 알림:** 볼륨 전환 상태 OSD 화면 표시 (상시 유지 옵션 포함)

### 🖥️ 동일 모델 다중 모니터 독립 식별
- **EDID Serial 기반 정밀 식별:** 프로필 식별 시 가능한 경우 모니터 내부 EDID 시리얼 넘버 기반의 고유 `monitorKey` 사용
- **다중 모니터 설정 뒤바뀜 방지:** 동일 모델 모니터를 2대 이상 연결하여 사용하더라도 각 모니터의 프로필, 토글, 게임 자동 적용 상태가 독립 유지
- **다단계 폴백 매칭:** EDID Serial ➔ Windows PNP Device ID ➔ `DISPLAY` 링크 런타임 보조키 순으로 안전 폴백

## 📁 데이터 저장 위치

모든 설정, 백업, 로그, 이미지는 로컬 앱데이터 폴더에 안전하게 격리 보관됩니다.

```text
%LOCALAPPDATA%\DisplayProfileManager
├─ config\  (GammaManager.ini 메인 설정)
├─ state\   (시작 시점 원본 화면 백업)
├─ logs\    (프로그램 구동 로그)
├─ backup\  (수동 프로필 백업 INI)
└─ images\  (custom-banner.png 사용자 이미지)
```

> 💡 프로그램 내 **📁 설정 / 로그 폴더 열기** 버튼으로 즉시 접근할 수 있습니다.

## 🛠️ 소스 빌드

### 준비물

- Windows
- Visual Studio 2022 또는 호환되는 Visual Studio 버전
- .NET Framework 4.7.2 Developer Pack

### 빌드 방법

1. 이 저장소를 내려받거나 복제합니다.
2. 솔루션 파일(`Display-Profile-Manager.sln`)을 엽니다.
3. `Debug | Any CPU` 또는 `Release | Any CPU`를 선택합니다.
4. 솔루션을 빌드합니다.

빌드 결과 폴더:

```text
Gamma Manager\Display-Profile-Manager-v1.5.6\
```

실행 파일:

```text
Display-Profile-Manager-v1.5.6.exe
```
