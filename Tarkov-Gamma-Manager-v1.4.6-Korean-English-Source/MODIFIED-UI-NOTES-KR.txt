Tarkov Gamma Manager v1.4.6 - UI Update

변경 내용
- 제공된 디자인 이미지와 비슷한 다크 카드형 레이아웃으로 정리
- 상단 한국어 / English 언어 전환 버튼 추가
- 언어 선택을 GammaManager.ini의 [Settings] Language 항목에 저장
- 현재 선택 언어 버튼을 파란색으로 표시
- 테마 버튼에 아이콘을 추가하고 상단 언어 영역과 함께 배치
- 기존 GPU/모니터/프로필/백업/업데이트 기능은 기존 이벤트 연결을 유지
- 기본 언어는 기존 설치와 호환되도록 한국어

빌드
- Visual Studio에서 'Tarkov-Gamma-Manager-v1.4.sln'을 열고 Release로 빌드하세요.
- 대상 프레임워크: .NET Framework 4.7.2

[2026-08-22] Large Modern UI Layout
- 메인 창을 1440x900 고정 크기로 확대.
- 참고 이미지 비율에 맞춰 좌측 설정 영역과 우측 유틸리티 패널을 재배치.
- GPU/모니터 슬라이더, 수치 입력칸, RGB 버튼 영역의 폭과 간격을 정렬.
- 모니터 조절 사용 체크박스를 모니터 설정 제목 오른쪽으로 배치하고 기본값은 해제.
- 우측 이미지/백업/불러오기/업데이트/항상 위 버튼 영역을 확장된 창에 맞게 정렬.
