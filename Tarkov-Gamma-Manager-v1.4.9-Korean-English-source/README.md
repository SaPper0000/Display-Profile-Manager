# Tarkov Gamma Manager v1.4.9

> ## ⚠️ 관리자 권한 실행
> **게임을 실행한 상태에서 글로벌 핫키를 사용하려면 프로그램을 관리자 권한으로 실행해야 합니다.**

Escape from Tarkov 할 때 **감마 / 밝기 / 대비 / 채도 같은 화면 설정을 프로필로 묶어서 편하게 바꾸는 Windows용 프로그램**입니다.

게임이 활성화되면 자동으로 프로필을 적용할 수도 있고, 글로벌 핫키로 원하는 프로필을 바로 적용하거나 Toggle로 잠깐 바꿨다가 이전 상태로 돌아올 수도 있습니다.

여러 대의 모니터를 사용하는 환경도 고려해서 **모니터별 설정과 프로필**을 관리할 수 있습니다.

> ⚠️ 이 프로그램은 Battlestate Games 또는 Escape from Tarkov의 공식 프로그램이 아닙니다.

## ✨ v1.4.9 주요 변경사항

이번 버전에서 가장 많이 손본 부분은 **프로필 우선순위와 Game Auto / Toggle / 초기화가 서로 꼬이지 않도록 상태를 정리한 것**입니다.

여기에 모니터 밝기·대비 적용 안정화, 로그 저장, Game Auto On/Off, 프로필 다중 선택 삭제도 같이 정리했습니다.

### 🔀 프로필 우선순위 정리

여러 경로에서 프로필이 동시에 적용될 수 있기 때문에, 현재 어떤 상태가 우선되는지 명확하게 관리합니다.

실제 프로필 적용 우선순위는:

```text
수동 핫키 / Toggle
      ↓
Game Auto
      ↓
Base / 원래 상태
```

`Hard Reset`은 위 우선순위에 끼는 프로필이 아니라, **언제든 현재 상태를 정리하고 프로그램 시작 당시의 원본 상태로 복구하는 별도의 강제 초기화 기능**입니다.

### 예를 들면

```text
프로그램 시작
  └─ 원래 상태 캡처 (예: 50/50)

게임 실행
  └─ Game Auto → A 프로필

B 프로필 Toggle ON
  └─ A 위에 B 적용

Alt+Tab
  └─ B 상태 유지

B Toggle OFF
  └─ Toggle 이전에 캡처한 원래 상태 복구 (예: 50/50)

게임으로 복귀
  └─ Game Auto → A 프로필 재적용
```

이렇게 **Game Auto와 Toggle을 같이 사용해도 이전 상태를 잘못된 프로필로 복구하지 않도록** 런타임 상태를 따로 관리합니다.

### ♻️ Hard Reset 개선

초기화 버튼은 단순히 `50/50`으로 만드는 버튼이 아닙니다.

프로그램 시작 시 캡처한 **실제 원본 디스플레이 상태**를 기준으로 복구합니다.

- 원래 모니터 밝기 / 대비 복구
- 원래 Gamma 상태 복구
- 현재 Toggle / Game Auto 상태 정리
- 예약된 지연 재적용이 초기화 결과를 다시 덮어쓰지 않도록 정리
- DDC/CI 핸들을 다시 확인하고 적용 결과 검증

프로필을 여러 번 바꿔도 마지막에는 **프로그램 시작 당시 상태로 돌아가는 것**을 목표로 합니다.

### 🖥️ 모니터 밝기 / 대비 적용 개선

일부 모니터는 게임 실행이나 전체화면 전환, 디스플레이 상태 변경 후 기존 DDC/CI 핸들이 제대로 동작하지 않을 수 있습니다.

이번 버전에서는 필요한 경우 물리 모니터 핸들을 다시 획득하고 실제 적용값을 확인하도록 보완했습니다.

```text
밝기 적용
  ↓
실제 값 확인
  ↓
대비 적용
  ↓
실제 값 확인
```

그래서 **Gamma는 바뀌는데 모니터의 실제 밝기 / 대비만 안 바뀌던 상황**을 줄이는 데 초점을 맞췄습니다.

> 모니터가 DDC/CI를 지원해야 하며, 모니터 / 드라이버 / 케이블 / 디스플레이 구성에 따라 하드웨어 제어가 제한될 수 있습니다.

### 📝 로그 저장 기능

프로필 적용이나 Game Auto / Toggle 동작에 문제가 생겼을 때 확인하기 쉽도록 로그 저장 기능을 추가했습니다.

로그는 날짜별로 저장됩니다.

```text
Logs/
└─ TarkovGammaManager-YYYY-MM-DD.log
```

### 🔇 로그 저장 OFF

로그 저장을 OFF로 하면 **로그 기록 자체가 동작하지 않습니다.**

단순히 화면에서만 숨기는 방식이 아니라 내부 로그 작성 함수가 바로 종료되기 때문에 OFF 상태에서는 로그 파일을 만들거나 내용을 추가하지 않습니다.

또한 설정값이 저장되어 다음 실행에도 OFF 상태가 유지됩니다.

### 🎮 Game Auto On / Off

Game Auto 설정 창에서 **프로필 자동변경 On/Off**를 직접 켜고 끌 수 있습니다.

**ON**

```text
게임 창 활성화
    ↓
지정된 게임 확인
    ↓
Game Auto 프로필 적용
```

**OFF**

```text
Game Auto OFF
    ↓
Foreground 이벤트 Hook 해제
    ↓
Game Auto 상태 정리
    ↓
자동 프로필 적용 안 함
```

OFF 상태에서는 UI만 꺼지는 것이 아니라 **Game Auto 기능 자체가 동작하지 않습니다.** 프로그램을 다시 실행해도 저장된 OFF 상태가 유지됩니다.

### 🗑️ 프로필 다중 선택 삭제

프로필 관리 창에서 Windows 기본 선택 방식처럼 여러 프로필을 한 번에 선택해서 삭제할 수 있습니다.

- **Shift** → 연속된 범위 선택
- **Ctrl** → 개별 프로필 추가 선택

선택한 프로필을 삭제하면 해당 프로필에 연결된 핫키도 함께 제거됩니다.

## 🎮 주요 기능

### 게임 자동 프로필

지정한 게임 프로세스가 활성화되면 연결된 프로필을 자동으로 적용합니다.

게임 포커스를 벗어나면 이전 상태를 복구하고, 다시 게임으로 돌아오면 Game Auto 프로필을 적용합니다.

Game Auto 감지는 350ms 주기 폴링이 아니라 Windows의 **Foreground Window 이벤트(`SetWinEventHook / EVENT_SYSTEM_FOREGROUND`)**를 사용합니다.

즉, 활성 창이 변경될 때만 현재 프로세스를 확인합니다.

### ⌨️ 글로벌 핫키 / Apply / Toggle

각 프로필에 글로벌 핫키를 지정할 수 있습니다.

**Apply**

```text
핫키 입력 → 지정한 프로필 적용
```

**Toggle**

```text
첫 번째 입력 → 프로필 적용
두 번째 입력 → Toggle 이전 상태 복구
```

Game Auto가 이미 A 프로필을 적용한 상태에서 B Toggle을 사용한 경우에도, B를 끄면 무조건 A로 돌아가는 방식이 아니라 **Toggle을 켜기 전에 캡처한 상태**를 기준으로 복구합니다.

### 🖥️ 모니터별 디스플레이 설정

여러 대의 모니터를 사용하는 환경에서도 모니터별로 설정을 관리할 수 있습니다.

프로필에는 다음과 같은 설정을 저장할 수 있습니다.

- Gamma
- 밝기
- 대비
- AMD Saturation
- NVIDIA Digital Vibrance
- 지원 모니터의 DDC/CI 밝기 / 대비

### 🟥 AMD - Saturation

지원되는 AMD 환경에서는 디스플레이별 **Saturation(채도)** 을 조절할 수 있습니다.

### 🟩 NVIDIA - Digital Vibrance

NVIDIA 환경에서는 **Digital Vibrance(디지털 바이브런스)** 를 조절할 수 있습니다.

### 🌐 한국어 / English

프로그램 내부에서 한국어와 English를 선택할 수 있습니다.

- 실행 중 즉시 전환
- 선택한 언어 저장
- 다음 실행 시 마지막 언어 유지
- 주요 팝업 / 안내 메시지도 선택 언어에 맞춰 표시

### 🖼️ 이미지 표시 끄기

프로그램에 표시되는 이미지를 필요에 따라 끌 수 있습니다.

### 🖱️ 수치 입력 / 슬라이더

감마 / 밝기 / 대비 / 채도 등의 값을 슬라이더와 수치 입력으로 조절할 수 있습니다.

일부 수치 입력 박스는 마우스로 직접 조절할 수도 있습니다.

### 🔄 업데이트 확인

프로그램에서 최신 GitHub Release를 확인할 수 있습니다.

### 💾 백업 / 복원

프로필, 핫키, Game Auto 매핑 및 프로그램 설정을 백업하고 복원할 수 있습니다.

업데이트 전에는 기존 설정을 백업해 두는 것을 권장합니다.

## ⚙️ 사용 예시

Tarkov를 켤 때 화면을 더 밝고 선명하게 쓰고 싶다면:

```text
1. Tarkov용 프로필 생성
2. Gamma / 밝기 / 대비 조절
3. NVIDIA라면 Digital Vibrance 조절
   AMD라면 Saturation 조절
4. 프로필 저장
5. Game Auto에서 Tarkov 실행 파일 지정
6. Game Auto ON
7. Tarkov 실행 → 프로필 자동 적용
```

원할 때만 특정 프로필을 잠깐 쓰고 싶다면:

```text
1. 프로필에 글로벌 핫키 지정
2. Toggle 사용
3. 핫키 입력 → 프로필 적용
4. 다시 입력 → 이전 상태 복구
```

## 🔒 안티치트 관련 안내

이 프로그램은 게임 내부 기능을 조작하는 프로그램이 아니라 **Windows 디스플레이 설정과 포그라운드 게임 감지를 이용하는 모니터 프로필 관리 도구**입니다.

현재 소스에는 다음과 같은 게임 개입 기능이 포함되어 있지 않습니다.

- 게임 메모리 읽기 / 쓰기
- DLL Injection
- 게임 DLL Hooking
- 커널 드라이버
- 게임 파일 수정
- 패킷 조작
- 게임 메모리 스캔
- 게임 화면 캡처

Game Auto는 Windows의 foreground-window 이벤트와 일반적인 프로세스 정보를 사용해 **어떤 프로그램이 활성화되어 있는지 확인하고 프로필을 적용**합니다.

> ⚠️ BattlEye를 포함한 안티치트의 탐지 방식과 정책은 개발자가 통제할 수 없으며 향후 변경될 수 있습니다. 따라서 어떤 환경에서도 "절대 탐지되지 않는다"고 보증하지는 않습니다.

## 📦 설치 및 실행

별도의 설치 프로그램 없이 사용하는 포터블 방식입니다.

1. GitHub Releases에서 원하는 버전의 ZIP을 다운로드합니다.
2. 압축을 해제합니다.
3. `Tarkov-Gamma-Manager-v1.4.9-Korean-English.exe`를 실행합니다.
4. 처음 사용하는 경우 모니터 / 프로필 / Game Auto / 핫키 설정을 확인합니다.

게임 실행 중 글로벌 핫키를 사용하려면 프로그램을 **관리자 권한으로 실행**해야 합니다.

## 🛠️ 직접 빌드하기

Visual Studio에서 솔루션을 열어 직접 빌드할 수 있습니다.

- 대상 프레임워크: **.NET Framework 4.7.2**
- 구성: **Release**
- 플랫폼: **Any CPU**
- `Prefer32Bit=false`

솔루션 파일:

```text
Tarkov-Gamma-Manager-v1.4.sln
```

일반 사용자는 직접 빌드하지 않고 GitHub Releases에서 제공되는 배포 파일을 사용하는 것을 권장합니다.

- AMD Saturation / NVIDIA Digital Vibrance는 GPU 및 드라이버 환경에 따라 지원 여부가 달라질 수 있습니다.
- 일부 모니터에서는 DDC/CI를 통한 밝기 / 대비 읽기 또는 변경이 제한될 수 있습니다.

- 이 프로그램은 Battlestate Games의 공식 프로그램이 아닙니다.
- 안티치트의 정책이나 탐지 방식은 개발자가 통제할 수 없으므로 게임 이용 제한이 발생하지 않는다고 보증할 수 없습니다.
